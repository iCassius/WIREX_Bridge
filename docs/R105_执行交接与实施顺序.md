## 当前边界

- runtime core 能承载多组 RX/TX 策略；launcher 的复杂 schema2 仍受旧配置投影限制，用户目前不能在正式 UI 中点选和编辑多组路由。
- IPC policy 更新命令和 WPF 多路由按钮/状态尚未实现。当前只做了 status validator 对 `stopping` 的兼容。
- `bm_routing_lifecycle_test` 使用真实 codec 代码和合成 DMRD，但外层播放/HRI/BM 发送结果由 fake ACK 驱动；不能据此声称 HRI、BM 服务端、WinMM、PTT 或 RF 已经在实机验证。
- 本轮没有访问真实 BM 网络或设备，没有执行 Quick call、真实语音、PTT 电气状态、RF 或 HIL 验收。用户已将实机验收延后到 UI/IPC 入口接入后的合并测试阶段。
- 当前状态仍是工作树修改；不要把这些未提交修改表述成 alpha6 或新的 release。
