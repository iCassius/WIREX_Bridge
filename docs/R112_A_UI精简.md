# R112-A 单页界面精简

## 界面范围

主窗口保留连接、设置和“停止并退出”三个顶栏操作。A 区用于显示当前收听配置、当前来话和来话历史；B 区用于选择下一起呼目标、管理本机收藏，以及输入 TG/TS。设置窗口继续提供 BM 连接参数、收听路由、组呼和来源屏蔽、私呼规则、发射许可、设备选择和音量滑块。

无当前来话、历史记录、收藏、设备发现结果或运行指标时，对应行与卡片折叠。UI 不用“未知”、破折号、零值或说明文字代替尚未取得的数据。HRI/BM 连接状态仅在核心报告有效状态时显示；RF 状态和 LCD 字段仍没有可显示的实测结果，因此主窗口不提供这些状态行。

## 当前数据行

- 顶部显示核心、HRI 和 BM 的简短状态；无状态值的 HRI/BM 卡片会隐藏。
- A 区的来话呼号按已取得的 Radio ID 资料更新，并保留数字 DMR ID；来话主行只显示组别或私呼目标及 TS。资料查询错误只显示简短错误；历史列表只在收到真实来话后出现。有历史记录时隐藏重复的“最近来话”卡片。
- B 区显示本机保存或已选择的下一起呼目标、发射许可、可用的本机目标和收藏。没有已配置目标时仍保留目标选择、收藏和 TG/TS 操作入口。
- A 区收听摘要只列实际组呼和私呼配置，不展开 peer ID、本机 ID 与屏蔽规则细节；完整规则仍可在设置中编辑。
- “收听来源”默认收起；只有核心上报真实观察来源时才显示。展开后每条来源提供已实现的停止/恢复本地收听、屏蔽/恢复和适用时设为起呼目标操作；没有观察来源时整块隐藏。来源行只显示实际呼号、DMR ID、组/目标和 TS。
- 底部只显示取得有效样本后的 BM 往返毫秒、有效分母下的 DMRD 丢包百分比和已上报的播放增益/削波样本。丢包只显示百分比；`expected=0` 时隐藏，实测 `0%` 照常显示。
- “音量”打开设置窗口的播放增益滑块。Native 当前没有运行时增益 IPC，滑块继续按已有行为保存并在下次连接使用，主窗口不提供看似实时的增益控制。

操作错误显示为短文本。界面不通过长 tooltip、页脚说明或运行状态面板讲解产品流程；设置中的少数 ID 输入框只用字段名 tooltip。

## RenderOnly 验收

`tools/test-ui-render.ps1` 使用离线样例检查无数据行隐藏、有效样例行显示、0% 丢包合法、A/B 操作区和设置路由控件可见，并渲染 1280×900 与 1024×728。RenderOnly 样例在测试 artifact 和预览标记中注明为模拟数据；它不启动 Native 核心、不读取 COM/音频设备、不连接 BM，也不执行 PTT 或 RF 操作。

布局验收不能证明 Radio ID 网络查询、设备发现、Native 实际状态、BM 网络指标或 RF/LCD 行为。它只确认 WPF 窗口在这两个工作区尺寸下的布局与已绑定数据形状。
