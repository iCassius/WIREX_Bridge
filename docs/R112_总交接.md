# R112-A 集成总交接（alpha10）

## 范围与当前状态

R112-A 集成三项内容：新来话 DMR ID 的后台 RadioID 查询及窗口退出收尾；BM 往返时间、DMRD 序号/丢包、接收队列和已有 PCM 削波数据；主窗口数据行精简。没有更改 DSP、音频排程或既有语音路径。

alpha10 代码与文档正在等待最终 UI 复审冻结，随后进行本地集成提交和 clean full39 构建。当前已推送的 Native 指标阶段提交是 `a726472`；本轮其余源码、UI、发布脚本和文档改动仍待集成。alpha9 仍是可用版本；alpha10 包尚未生成或通过根包审计，未切换 `bridge-directory.txt` 或移动旧包目录。

## 实施结果

- 来话先显示数字 DMR ID，再异步请求单条 RadioID 资料。有效缓存直接使用；同 ID 请求合并，单 worker、队列上限16、最少1秒请求间隔、HTTP 5秒超时和递增失败冷却。迟到结果按 `run_id`、来话代次和 DMR ID 校验后才更新对应记录。
- 身份查询失败不会停止来话、播放、路由或发射许可。查询错误写入用户配置目录下的 `identity-query-errors.jsonl`；不写 DMR ID、呼号或完整资料。用户退出时清空队列、结束后台管线并释放独占 runspace；保留原有8秒清理上限。
- Native 报告已成功发送的 RPTPING 到有效 MSTPONG 的客户端往返时间估计、DMRD 相邻序号推断缺包、重复/逆序数据报、通话/会话累计值、接收队列帧数和现有 PCM 削波数据。无样本时输出 `null`，界面收起无数据行；`0%` 有效样本保留显示。
- 独立 `bm_network_probe` 之前只放行 `control` 包，修复后也发送 `keepalive`；成功 UDP send 后才回调 RTT 记账，启动控制包仍按前缀去重。
- A 区显示当前收听配置、来话和真实历史；B 区显示起呼目标、许可、可用目标与本机收藏；底栏显示实际报告的往返、丢包、增益和削波数据。没有数据的卡片或行隐藏。主窗口不提供 LCD 或 RF 状态入口。
- FTX-1 LCD 呼号显示、FM RF 发射和 C4FM RF 发射链尚未实现。Native 没有运行时增益 IPC；音量滑块保存设置并在下次连接使用。
