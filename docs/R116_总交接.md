# R116 alpha.12 总交接

日期：2026-10-30。alpha.12 集成 CAT-1 用户操作，保留现有 DIRECT 桥接、R112 网络音频指标和 R113 来话身份写出。用户已将 FTX-1 LCD 改为独立实验方向，不作为 alpha.12 主线功能。

## CAT 能力与 UI 边界

[CAT 能力与控制实现](R116_CAT能力与控制实现.md) 记录官方命令和值域、CAT 模块接口、一次性串口会话和真实读查询观察。[电台控制界面](R116_电台控制界面.md) 记录 UI 控件、单操作调度、本机偏好及写操作条件。

alpha.12 UI 可查询 CAT-1 机型 ID、TX 状态、MAIN/SUB 频率、无线机模式和 PC 功率控制值；可设置 MAIN 频率、无线机模式以及 PC 功率控制值。C4FM-DN 与 C4FM-VW 分开显示。无线机模式读回只报告 FTX-1 的 CAT 状态，不报告 HRI 正在使用的语音或数据路径。

每次操作打开短时 CAT-1 串口会话并核对 ID0840。设置前还会读取 TX 状态，只有 TX0 才发送一条设置命令；操作之后读回并比较，不自动重试。设置 MAIN 频率或无线机模式时 UI 先停止 WIREX Bridge 核心，成功或失败后保持断开。功率设置可在核心进程仍运行时执行，但要求最近 3 秒内无活动通话、接收媒体空闲或已过滤且接收队列为空；CAT 模块仍会在写之前重新核对 ID 和 TX 状态。功率路径和限制只取本次 PC 读数，PC 值表示控制设定，不是射频输出测量。

HRI MODE 和 WIRES-X Node Mode 没有公开 CAT 命令，本版不提供自动切换或猜测的 EX 菜单地址。R116 静态研究将 MAIN V0113 的 Node Mode 数值标签映射为 0=AP RADIO、1=AP PC、2=DIRECT，但没有证明 CAT 地址、保存行为或运行服务切换；详见 [HRI/NodeMode 控制路径研究](../../research/r116/hri-control/R116_HRI开关NodeMode与GMX控制路径.md)。用户仍按官方面板流程设置 HRI MODE 和 GM/X。

## 本机偏好与发行边界

电台偏好文件名为 radio-control-preferences.json，跟随 UI 解析得到的本机 UserConfigDirectory；默认便携目录为 private/user-config。打开设置窗不会创建偏好文件，用户保存设置时才写入。初始偏好包括 COM11、38400/8N2 和期望功率 25 W；若 Windows 未枚举到 COM11，UI 会将已保存端口标成未发现，不造出假设备项。25 W 是用户期望值，不会因启动、查询或保存偏好自动写入电台；如果本次读取的功率路径上限低于 25 W，应用会保留原偏好并报告请求不适用，不会自动降低数值后写入。

alpha.12 profile 沿用 alpha.11 全部 32 个普通资产，另加入 RadioCat.psm1 和两份 R116 说明，共 35 个普通资产及单独的 manifest.json。R112 网络音频指标、R113 LCD 核心说明与身份接线历史文档都继续保留。通用包清单明确排除 radio-control-preferences.json、RadioID 缓存、密码与个人配置目录指针。alpha.12 用户说明见 [包内说明](releases/v0.1.0-alpha.12-package-README.md)，范围与验收记录见 [alpha.12 本机测试版记录](releases/v0.1.0-alpha.12.md)。

## LCD 实验结论

LCD 只作实验研究，当前不作为 alpha.12 主线能力。用户在官方 DIRECT/HRI 环境观察到没有来话或列表内容、底部软键无响应，红色指示灯行为与 Bridge 环境相同；这些现象尚未映射到底层设备状态。本版没有新增 LCD 操作或“显示成功”状态，也不把 Native 写出 SrcCallSign 记录说成屏幕绘制证明。

详细离线研究见 [LCD 实验逆向报告](../../research/r116/lcd-lab/R116_LCD实验性独立逆向报告.md)。研究没有操作硬件或发送 CAT；已经找到的 Node Mode 数值标签和 callback 字节也只证明 MAIN V0113 静态字段路径，不证明 HRI/Node Mode CAT 控制。
