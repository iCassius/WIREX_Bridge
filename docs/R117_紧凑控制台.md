# R117 紧凑控制台

## 布局

主窗口采用固定的深色三段式控制台。顶部约占窗口高度的 45%，显示核心、HRI、电台和 BM 的有效状态，并用大字号显示当前来话来源。呼号与姓名来自本机资料；资料缺失时显示 DMR ID。没有当前来话时收起来源行。

底部约占窗口高度的 55%，左侧连接配置占约 40%，右侧日常控制占约 60%。左侧包含 BM 服务器与端口、Gateway/本机 DMR ID、色码、HRI 串口、音频输入输出、CAT 串口和 BM API key 文件路径。连接后锁定左侧配置；停止或断开后解锁。右侧保留当前收听组、起呼目标与发送许可、动态组、本机收藏、音量、电台功率和 BM 静态组操作。

布局使用 WPF 当前运行链和自定义深色控件模板实现 Qt 风格外观，没有增加 Qt 运行依赖。窗口不能拖拽重排面板；窄窗口下左右内容保持各自滚动，连接与保存按钮固定在配置区底部。

## 数据与操作边界

- 动态组加入、激活和本机 RX 监听是不同操作。本机收藏只保存在本机，不显示成 BM 静态订阅。
- BM 静态组仅在用户配置 key 文件路径且成功读取远端列表后显示。偏好文件只保存路径，不保存 key 正文。新增或删除后，界面分别显示写入已接受和远端读回确认状态。
- HRI 串口、音频端点和 CAT 串口独立枚举。CAT 目录通过 `RadioDevices.psm1` 从注册表与 CIM 读取；`CatMatchRank` 只用于优选显示，不会打开串口。
- CAT 默认端口为自动选择。已保存的端口只有在当前枚举中存在且不是 HRI 端口时才恢复；否则重新按唯一最高匹配评分选择，无唯一匹配时留空等待用户明确选择。
- 连接成功后 CAT 先读取一次真实电台状态，随后每秒最多启动一个有界只读查询。查询读取的实际值与用户编辑草稿分别保存；成功读回后才清除草稿。停止退出会先停 CAT 轮询，再等待核心停止。
- 本轮 UI 验收没有启动真实桥接核心、没有打开 CAT 串口、没有发送 BM 写请求，也没有执行 RF/PTT。

## 验收记录

- `tools/test-ui-console.ps1`：当前源码在 PowerShell 7 与 Windows PowerShell 5.1 STA 下各通过 78 项真实 WPF 交互断言，覆盖连接锁定、CAT 首读/轮询/草稿隔离/超时、拒绝后的准确读回和停止退出。
- `tools/test-ui-console.ps1 -LiveSerialReadOnly`：PowerShell 7 与 Windows PowerShell 5.1 STA 下各通过 16 项断言。真实串口目录经生产 runspace 从本机注册表与 CIM 读取，并发布到 WPF CAT 下拉；未打开 COM、启动 CAT 查询或桥接核心。
- `tools/test-radio-devices.ps1`：通过 18 项串口分类和匹配断言，使用合成设备记录，没有打开串口。
- `tools/test-ui-render.ps1`：Windows PowerShell 5.1 STA 通过 79 项 RenderOnly 布局与对比度断言，分别检查 1360×850 和 1024×700。运行时只创建空包标记，不启动标记文件。
- RenderOnly 截图和 `layout-info.json` 保存在该测试输出目录的 `normal/` 与 `small/` 子目录。`main-combo-open.png` 是实际展开服务器下拉后的视觉树截图。渲染主窗口展示的呼号、来话、路由和音量数据均为明确标记的离线样例。

RenderOnly 渲染验证不是硬件或无线验收。CAT 端口选择来自当前机器的只读注册表/CIM 目录；真实电台读写、BM 账户写入和 RF/PTT 操作仍需独立授权与专门验证。
