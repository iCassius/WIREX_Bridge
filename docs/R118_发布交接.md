# R118 Alpha 14 发布准备交接

## 目标包合同

Alpha14 以 alpha13 固定目录、Native 测试清单与 40 项测试顺序为基础，仅新增 `ui/windows/PortableConfig.psm1`。包内 asset 名固定为 `ui__windows__portable-config.psm1`。根目录只保留唯一 `start-wirex-bridge.cmd`，映射自 `tools/start-wirex-bridge-alpha14.cmd`；PowerShell 入口映射自 `tools/start-wirex-bridge-alpha14.ps1` 到 `tools/start-wirex-bridge.ps1`。用户 README 来源为 `docs/releases/v0.1.0-alpha.14-package-README.md`。内部 R118 设计文档不进入用户包。

正式 Start 从 launcher 所在的 `packageRoot` 直接启动 UI，只传 `PackageDirectory`，不查找 `private/user-config-directory.txt`，不传默认 `UserConfigDirectory`。UI 以 `packageRoot/config.json` 为唯一运行设置文件。设置文件不存在时读取默认值不落盘；用户保存设置或连接时才创建文件。移动程序时移动整个目录。

`PrepareOnly` 沿用独立合成 profile 和临时状态文件；`RoutingDiagnosticAutoTest` 必须显式给独立临时 `UserConfigDirectory`。这两个入口只验证包级行为，不连接 BM、不打开 COM、不启动 PTT。

## Generic 包保护

- Package、publisher、downloader 的 alpha14 inventory 都固定到同一 allowlist，不接收额外文件或目录。
- manifest 排除列表要求包含 `config.json`、`config.*.backup*`、`credentials/`、`tempSecrets/`，并保留遗留个人偏好排除项。
- `private/user-config` 不在 alpha14 资产目录中；没有配置模板的宽泛 ignore 规则。
- `config.json` 只允许运行时在用户自己的发行文件夹中创建。本切片没有读取或迁移 canonical 用户配置。
- BM 密码/API Key 通过 UI 内存参数传递并保存在统一配置。未增加自建加密或口令框架。
