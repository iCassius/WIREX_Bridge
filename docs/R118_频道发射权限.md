# R118 频道发射权限

## 用户选择与发射权限

频道 ID 91 和 46001 不再因为号码而被 Native 路由层自动拒绝发射。手动保存的合法频道 ID 范围为 1 到 16,777,215；用户选择的起呼频道按当前 `transmit_enabled` 权限处理。选择频道只会设置起呼目标，不会自动发射；按下手咪 PTT 才会开始常规发射，Quick Call 仍要求用户明确执行加入操作。

`listen-91` 和 `listen-46001` 是明确的只收预设。它们通过 preset 的 `listen_only` 字段保持 `transmit_enabled=false`。启动参数 `--listen-only` 也会关闭本次运行的发射权限。只收启动期间，UI 控制协议不能把权限改为开启；Native 回调使用既有 `invalid_policy` 结果拒绝提升权限。

已配置的 `dynamic_join_blocked_group_ids` 仍阻止相应 ID 的 Quick Call。TG4000 的 Quick Call 保护仍由现有协议验证保留。普通路由不再自动把 91 和 46001 放入 deny-list。

## 修改范围

- 移除启动路由解析、UI 路由命令、PTT 起呼和 Quick Call 中按 ID 对 91/46001 的默认发射拦截。
- 将只收意图放在显式 preset 字段和 `--listen-only` 启动参数上。
- 限制运行时路由回调：只收启动不能通过 `tx_policy.replace` 提升为可发射。
- 保留有效 ID、呼叫类型、Timeslot、明确 deny-list 和 TG4000 Quick Call 校验。
