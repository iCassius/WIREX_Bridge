# R118 频道控制台

## 目标与范围

主窗口把有序的 `channels` 列表作为监听和 PTT 目标的唯一来源。频道以 `(kind, id, slot)` 区分；`kind` 为组呼或单呼，`slot` 为 TS1 或 TS2。界面不提供收藏区或用户可关闭的发射总开关。静态 BM 网页订阅由 BM 服务管理，本机取消监听只修改本机频道列表。

本轮改造覆盖 WPF 主窗口、频道高级设置、连接与 CAT 控件、BM 管理 API 凭据输入，以及从根配置生成旧 Native 运行会话材料。CAT、PortableConfig、Native 路由兼容和发布器分别由并行工作项维护。

## 根配置与临时文件

正式运行读取并保存软件目录下唯一的 `config.json`。显式隔离的测试目录仅供 RenderOnly、UiTestFixture、OfflinePreview 和 RoutingDiagnostic 使用。PortableConfig 模块负责校验、原子保存和未知字段保留。连接密码和 BM API key 在设置页面使用 PasswordBox 输入；API key 直接以内存字符串传给 BM 管理模块。

Native 仍需要旧格式配置时，UI 从根配置派生到系统临时目录中的单次会话材料。密码只写入该会话临时目录，不放进进程命令行。正常停止、失败或窗口退出会删除会话目录；清理失败时保留路径并再次尝试，不能开始另一个会话覆盖它。

## 频道行为

- 新配置默认建立单呼 460997 / TS2 频道，并将它设为 PTT 目标。已知 460997/9990 预设为单呼，91/46001 预设为组呼；其他 ID 要明确选择组呼或单呼。
- 新频道加入后即成为本机监听项；如果它是首个频道，也默认成为 PTT 目标。列表允许为空，空列表没有 PTT 目标。
- RX 规则由未静音频道生成。组呼按目标 ID 和时隙匹配；单呼按对端来源 ID 和本机 destination ID 匹配。单呼回源时不能用 destination ID 等于对端 ID 的方式筛选。
- 临时屏蔽只在运行期间静音该频道，不改动 PTT 选择；收听规则替换获核心确认后停止当前频道的播放。重新收听也通过 RX 策略替换确认。
- 取消监听会移除本机列表项，不会删除 BM 网页订阅。移除当前 PTT 目标后选择剩余列表首项。运行中删除最后一个频道时，先正常停止核心；只有成功停止后才保存空列表。失败时保留原频道。
- 历史列表和当前频道来话卡分开显示。来话卡按组呼目标或单呼来源匹配频道，异步身份查询结果只写入对应频道卡。
- 频道激活组呼沿用明确的用户点击操作；启动时不自动呼叫保存的所有组。临时组激活不发送语音。

## 当前控件与代码合同

主窗口使用 `ChannelCardsPanel` 显示每个监听频道及该频道当前来话，卡片头部提供取消监听和临时屏蔽；`ChannelListPanel` 以紧凑项目显示 PTT 选择、时隙高级入口和组呼激活。输入区使用 `ChannelIdBox`、`ChannelKindBox` 和 `AddChannelButton`。`CallHistoryList` 单独保留历史。CAT 波特率可选且默认 38400，内部停止位固定 Two（8N2）；主窗口只显示可编辑端口和观测到的模式、频率、功率，不显示停止位选择、设备 ID、来源时间或常驻操作说明。

主窗口不再有重复事件列表。`Add-UiEvent` 只在事件列表控件存在时写入；当前界面移除了该控件，简短错误、CAT 串口离开目录和恢复状态会显示在 `FooterText`。设置页中的密码与 API key 使用 `PasswordBox`；连接字段只在用户保存时一起保存，API key 编辑后单独保存自身字段。播放与麦克风增益在滑块改变时单独保存，CAT 功率仅在设备确认后保存。设置窗关闭后释放窗口引用，下次打开会创建新实例。

频道变更通过 `Start-UiChannelMutation` 创建待确认状态，由 `Complete-UiChannelMutation` 在核心 ACK 后提交到 UI 和根配置。TX 已 ACK、但后续 RX 更新发送失败、遭到拒绝或超时，或任何 TX 结果超时/无法确认时，UI 丢弃待提交频道并请求正常停止；停止确认前锁定操作，停止后保留原频道和配置并允许手动连接。TX 初始命令明确遭到拒绝时不会停止，也不会提交候选。两项策略确认后若根配置保存失败，界面仍显示已确认运行目标并明确报告保存失败。Native 意外退出时也会清除未确认候选，不写入配置。运行时静音集合只保存在内存。RX 策略使用 Native `rx_policy.replace`，PTT 目标使用 `tx_policy.replace`，协议中的 `transmit_enabled` 固定为 true；没有频道时不启动或发送 PTT。
