# R119 用户界面改进

日期：2026-11-01。

本轮按六项用户实测反馈调整 WPF 主窗口和设置流程。改动集中在现有 `bridge-ui.ps1` 与 XAML，不增加运行时模块或发行资产。根配置仍是唯一用户配置来源；自动测试只在系统临时目录使用合成配置。

## 主窗口

- BM 卡片把连接状态和往返时延排在同一行。时延紧跟连接状态，留出约 8 px 间距。RenderOnly 使用合成的 `42 ms · 3 次` 仅用于布局验收。
- 监听频道卡片固定为 120 px，呼入内容区固定为 52 px。空闲频道保留相同尺寸的空白，不显示“暂无来话”。当前 PTT 频道由绿色边框和“✓ 呼叫目标”按钮表示，不再重复显示说明文字。
- 每张频道卡右侧固定为 2×2 操作区：选择下次呼叫目标、取消监听、临时屏蔽/恢复收听，以及真实存在的第四项操作。组呼的“更多”菜单提供动态组激活和时隙设置；单呼卡直接打开时隙设置。选择下次呼叫目标只发送现有 `tx_policy.replace`，不会启动 QuickCall 或发射语音。
- 删除了下方重复的频道清单。新增频道仍从 ID、类型、加入监听入口操作；“同时设为 PTT 目标”复选框和输入区高级时隙入口保留。既有频道的操作集中在上方卡片。
- BM API Key 和 BM 密码标签后增加“设置”超链接，分别打开官方 Profile 与 SelfCare 页面地址。只有用户点击时才调用系统默认浏览器，不自动提交字段。API Key 可在连接期间编辑保存；密码仍按连接参数锁定。空 API Key 不阻止 BM 连接。
- 电台控制标题后同一行显示已观测到的模式、频率和功率。控件和值沿用 CAT 控制器现有字段，没有新增查询源。CAT 输入仍允许编辑，ComboBox 整个框均可点击展开。
- 播放和发送增益只显示基础值，不显示旧的削波计数文本。

## 实时增益

仅当本次 Native run 在 `control_ready` 和 `hello` 两端都声明 `audio.gains.set`，并完成同 run 状态读取后，连接中的两个增益滑块才启用。旧 Native 的 capability 列表和不带 `audio_gains` 的旧 status fixture 仍按原 schema 处理，不会影响 BM 登录。

UI 每次只发送一个音量命令。拖动时按 200 ms 节流发送最新两滑块值，未确认期间继续合并更新；旧 ACK 不回退较新的滑块草稿。协议参数严格为 `revision`、`radio_playback_gain_milli` 和 `mic_transmit_gain_milli`，请求 ID 为 `audio-gains-{revision}`。只有当前 run、当前 request、相同 revision 的 `ok` ACK 才会将 Native 实际读回值写入根配置。

拒绝、发送失败或等待超过 8 秒后，UI 查询 Native status 并用实际值校准滑块，不把未确认草稿写入配置、不重发过期 request。超时后到达的旧 ACK 会丢弃，不写配置。程序启动配置、status 校准、迟到消息和 ACK 驱动的滑块更新使用 programmatic guard，不产生新的命令或离线偏好保存。

热调 Native 只改变本次运行内存状态。Native 不写根配置。离线调节仍通过现有偏好保存流程写入根配置。

## 验证

- `tools/test-ui-audio-gain.ps1`：Windows PowerShell 5.1 STA 和 PowerShell 7 STA 均通过 81 项断言。测试使用真实 WPF MainWindow、fake Supervisor 与独立临时 `config.json`；覆盖协议字段严格校验、旧 capability/status 兼容、连续拖动、单 in-flight、ACK 实际值保存、程序化更新 guard、拒绝/timeout 状态校准、过期 ACK 不持久化、run 切换隔离和离线偏好保存。
- `tools/test-ui-channels.ps1`：Windows PowerShell 5.1 STA 和 PowerShell 7 STA 均通过 85 项断言。实际 WPF 操作验证选择 PTT 目标、组呼激活入口、时隙设置、取消监听与临时屏蔽；没有连接真实 BM 或发送 PTT/RF。
- `tools/test-ui-render.ps1`：通过 124 项布局、对比度和交互断言，分别渲染 1360×850 与 1024×700 工作区。渲染子进程使用 Windows PowerShell 5.1 STA，包目录和配置目录均为临时合成目录。主窗与设置窗截图及 `layout-info.json` 位于本次临时目录 `wirex-r118-render-af403a76c9e5492bae98e9a064d825cd`；两种尺寸的主窗截图已目视检查。
- R119 旧版 status、identity、lifecycle、radio-cat 和 console WPF 回归，由 CAT 工作项按当前磁盘版本在 Windows PowerShell 5.1 STA 与 PowerShell 7 STA 均重跑通过（5/5）；console 两版各120项断言。夹具只针对 UI 子树读取与新增状态变量作兼容初始化。
- 静态检查：`bridge-ui.ps1` 与三份 UI 回归脚本均通过 PowerShell AST 解析；主窗口和设置窗口 XAML 均通过 XML 解析。

这些检查使用 fake Supervisor、CAT 夹具、合成状态和临时配置，不访问真实 API、BM 网络、电台 COM、PTT、音频设备或 RF。
