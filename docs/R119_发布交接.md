# R119 发布交接：alpha15 本地目录准备

状态：只完成 alpha15 源码发布配置、独立启动器、包内说明和测试准备。没有重新构建 Native，没有生成 `build/releases/v0.1.0-alpha.15`，没有迁移本机配置，也没有创建 ZIP、Git tag 或 GitHub Release。root 冻结并审计之前，不把这些准备内容当成可交付候选包。

## 版本和资产范围

- 目标版本为 `v0.1.0-alpha.15`，发行形态为本地绿色文件夹。
- 包配置从 alpha14 继承固定资产和目录清单。alpha15 只将已有的包内 `README.md` 与 `tools/start-wirex-bridge.ps1` 对应到 alpha15 版说明及独立启动器源码；Generic 包资产路径总数不增加。
- 当前 profile 预计仍有 41 条 manifest 文件记录，加上 `manifest.json` 共 42 个文件。这个数量来自脚本清单，尚未由 alpha15 构建包实测。
- profile 暂时沿用 alpha14 的 40 项 Native 测试名称和顺序。是否通过这些测试要等 root 冻结后重新构建并核实构建 provenance；本准备没有生成或验证新的 Native 二进制。
- alpha15 的 Generic 包继续排除用户 `config.json`、配置备份、`credentials` 与 `tempSecrets`。新 launcher 和包内 README 位于既有清单路径，不新增运行时文件。

## alpha15 启动和能力兼容检查

`tools/test-package-startup.ps1` 已加入 alpha15 版本分支。冻结后的候选包运行该检查时，会从临时副本启动唯一 CMD，验证默认配置定位到副本根目录 `config.json`，并用包内 UI 和 `BridgeSupervisor.cs` 检查播放/麦克风增益能力兼容。

音量能力按 Native 协议合同验证：UI 接受 alpha14 没有 `audio.gains.set` 的旧 v2 命令表，也接受新增该命令的新命令表；仅新命令表启用运行中热调。Supervisor 对这个明确命令执行白名单检查，并限制完整 JSON 请求体为 4096 字节。动态命令/尺寸检查使用候选 Native 的 `--routing-diagnostic` 内存 sink；这项检查不打开实际音频设备或 HRI，不连接 BM，不操作 CAT/COM、PTT 或 RF。

## 本机设置接续

root 冻结、包审计和新候选验证通过后，个人 alpha15 配置应从当前 alpha14 发行目录的 `config.json` 复制，再在 alpha15 目录内验证字段并确认必要设置保留。不要从旧 canonical 配置目录重新导入，以免覆盖用户在 alpha14 期间做过的音量等调整。Generic 包始终不携带个人配置。当前尚未读取、复制或修改任何实际配置文件。
