# R120 UI 实施记录

## 当前进度

- 主窗口监听区使用固定 3 列 × 2 行、每页最多 6 个显示槽；频道总数超过 6 时显示紧凑页码，后台监听列表保持完整。
- 来话信息区固定高度；卡片操作区使用 2 × 2 网格。组呼卡直接提供“激活组”，私呼卡的第四格留空。
- 呼号已解析时，来话下方显示可打开 BrandMeister 呼号资料页的 DMR ID 链接；未知呼号仅显示 DMR ID，不生成未经核实的链接。
- 移除顶部核心、电台、音频状态卡；BrandMeister 在线状态和往返延迟已移至应用标题行。
- BrandMeister 状态现在紧接应用标题并左对齐，停止按钮仍靠右；长错误信息单独占标题下方一行。
- Wires-X 串口文字已调整。CAT 端口、波特率、“连接串口”/“断开串口”按钮和短状态已移入电台控制区，删除旧“读取电台”按钮。CAT 会话按独立生命周期处理：核心普通停止和意外退出不停止 CAT，退出应用时请求收尾。
- 桥接的 CAT 自动连接点只在非隔离启动且未传 `-NoAutoConnect` 时调用；隔离模式只有显式 fake hook 才能启动 CAT worker。普通 `-NoAutoConnect` 仍允许用户手动操作 CAT。
- 保存和新建 Wires-X 连接只按 CAT 公共状态 `user_action_busy` 判断；普通 CAT 状态查询期间仍可保存 BM 配置和启动 Wires-X，CAT 写入/排队动作期间暂时禁用并拒绝新 Wires-X 启动。
- Wires-X 启动准备前按保存的 HRI 端口检查 CAT 会话；设备预检完成后，再按校验后的最终 `--port` 检查一次。若端口相同，UI 显示具体 COM 口并取消这次 Wires-X 启动，CAT 会话不受影响。检查同时覆盖 CAT Disconnect 后仍在释放中的 worker 固定端口。
- 删除界面上的时隙入口和频道高级设置入口；已有频道的内部 slot 保留，新频道仍使用内部默认 slot 2。BM API Keys 设置链接直达 `https://brandmeister.network/#/profile/api`，密码设置链接直达 `https://brandmeister.network/#/selfcare`。

- 已人工查看两种尺寸截图。两种尺寸都显示 3 列 × 2 行监听区域；小窗口下连接配置和日常控制区通过滚动查看，连接/保存按钮仍完整显示。
