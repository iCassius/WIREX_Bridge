# R120 发布交接：alpha16 纯发布准备

状态：已准备 `v0.1.0-alpha.16` 的发布 profile、版本化启动器、包 README 和离线合成测试；alpha16 包尚未生成，也没有构建 Native。R120 UI、CAT 和 BM 源码及相应离线回归已完成；独立 review 结束后由 root 决定源码冻结、提交和构建。本轮没有迁移本机设置。

## 候选范围

- alpha16 延续 alpha15 的 Generic 包资产路径、目录、资产映射和 40 项 Native 测试名称/顺序。alpha16 只把既有包内 `README.md` 和 `tools/start-wirex-bridge.ps1` 映射到 alpha16 版说明与启动器源文件，不增加包内运行时文件路径或 Native 模块。
- 已有清单中的 BM 静态组模块和 UI 路径承载 R120 更新：静态列表从专用 talkgroup API 读取；添加按设备 status 选 API slot；界面只显示 TG 数字，移除仍使用原记录 slot。合同与公开证据见 [R120 BM 接口研究](R120_BM接口研究.md)。
- UI 变化包括每页 3×2 频道卡片、DMR ID/已解析呼号资料链接、隐藏用户可见时隙选择、标题栏 BM 状态和独立 CAT 控制。HRI 启动准备前及校验最终 `--port` 后均检查 CAT 占用；相同 COM 会取消此次 Wires-X 启动并保留 CAT，会话 worker 仍在收尾时也保留端口占用。
- alpha16 README 是候选发行包内说明。它不声称 CAT、设备、音频、BM 实机、PTT 或 RF 已通过验收。

## 用户配置边界

本轮没有读取、复制、改写、迁移或清理个人配置。若后续 root 批准本机 alpha16 配置接续，来源必须是当前 alpha15 发行目录的 `config.json` 原字节；不能从 canonical、legacy 或其他配置位置推断来源。Generic 包 profile 继续排除 `config.json`、配置备份、`credentials`、`tempSecrets` 和个人偏好文件。
