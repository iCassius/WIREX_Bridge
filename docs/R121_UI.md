# R121 固定主窗口布局

## 目标与基线

任务 R121，源码基线 `e51fd6db2e8af5eb8c0105bd0956f9b252b73b54`。主窗口固定为 1360×900，使用 `CanMinimize` 保留最小化操作；各面板固定在同一窗口内，不依赖滚动条查找控制。窗口尺寸按本机工作区只读核对结果 3440×1392 选择。

## 布局合同

- 顶部中央区域统一显示 BM 连接状态、RTT、loss 和成功/失败事件，标题留在左侧，停止并退出留在右侧。
- 监听频道继续使用 3 列 × 2 行固定卡片；来话历史固定 80 px，显示三条并提供页码和翻页按钮。
- 左连接区占主操作面板约 40%，按五行排列串口选择及组合连接控制、MAIN 模式/频率/功率、电台音频端点、BM身份/服务器/端口/色码/凭据、BM连接/断开及保存。
- `SerialConnectButton` 启动 HRI 与 CAT，并保持 BM 暂停；`SerialDisconnectButton` 先停 BM，再收尾 HRI 与 CAT。`ConnectButton` / `DisconnectBmButton` 单独控制 BM 会话。`StopButton` 退出时清理全部会话。
- 右日常区保留频道监听录入、BM静态组和播放/发送增益。BM静态组列表每页显示三项，历史和静态组列表均关闭区域滚动条；ComboBox 弹出列表保留其键盘导航。
- 频道卡继续固定六槽。2×2 操作区目标宽度约为 R120 旧宽度的 75%，为呼号与来话信息区留出更大横向空间；四个动作保持可用。

## 离线验证

- BM静态组 WPF fake 检查：Windows PowerShell 5.1 STA，72 项断言通过。覆盖空列表、三项分页、末页不足三项、选择行的 talkgroup/slot 保留，以及翻页不发 API 请求。
- RenderOnly 检查：214 项布局/对比度断言通过；默认和最小窗口用例均为 1360×900。呼号区 280.91×76 px，2×2按钮区宽 133.42 px，为 R120 对应宽度 175.53 px 的 0.76 倍。
- 来话历史外框固定 80 px，列表显示三项。RenderOnly 逐项测得容器高 15 px，三条文字高度 14.63 px，容器与文字均完全位于列表可视区域内。
- BM 静态组使用 4 条本地合成数据，每页显示 3 条并提供 1 / 2 翻页；实际可见文案为 TG 91、TG 92、TG 93，不显示 slot。BM fake 检查确认 talkgroup 与 slot 仍保留给移除操作。
- RenderOnly 遍历窗口可视 UI 树：可滚动的区域 ScrollViewer 数量为 0，可见非弹出滚动条数量为 0。ComboBox 弹出列表保留键盘导航。
- PowerShell AST 解析、主窗口及设置窗口 XAML XML 解析、涉及 PowerShell 文件的 UTF-8 BOM 检查和 `git diff --check` 通过。
