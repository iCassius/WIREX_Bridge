# R122 固定主窗口布局

## 范围与基线

任务 R122，源码基线 `b5482832d1c259645bfee7b7cecd1bf15cfee7fc`。主窗口固定为 1360×900，保留最小化操作，不使用区域滚动条。此文档记录本次 WPF 布局调整，不说明真实设备或网络验收。

## 布局合同

- 顶部标题与 BM 状态位于同一行并垂直居中；事件文字占其下方固定行。频道卡继续使用 3 列 × 2 行，来话历史保留 80 px 外框和三行分页显示。
- CAT 控件横向排列为 MAIN 模式、频率、功率和最右侧“应用”。一次操作由 `ApplyCatSettingsButton` 提交三项草稿。模式、频率保留可读宽度；串口选择、连接和断开使用同高并对齐底边的控件。
- CAT 操作结果使用固定单行状态区；长结果以省略号显示，悬停可查看完整内容。没有结果时状态文字为空。
- 下方连接配置区与日常控制区各占 50%。音频输入、输出选择位于右侧音量控制上方。日常控制外卡片保留，频道、BM 静态组、音频和音量分区使用标题与间距，不再嵌套装饰边框。
- BM 身份输入使用呼号、`SourceBox`（DMR ID）和两位设备编号。设备编号只接受最多两位字符，显示范围说明为 00–99；对旧 Gateway 值无法安全拆分的情况留空，保存/连接时保留原值。
- 频道录入只保留 ID、类型和“加入监听”。该按钮与输入框等高并对齐底边；呼叫目标仍在频道卡片单独选择。
- 主窗口中移除 `ApplyCatModeButton`、`ApplyCatFrequencyButton`、`ApplyCatPowerButton`、`GatewayBox`、`ColorCodeBox` 和 `MakeChannelTxTargetCheckBox` 的实际控件，不以隐藏控件保留旧入口。

## 离线验证

- `tools/test-ui-render.ps1` 在 Windows PowerShell 5.1 STA 下通过 2128 项 RenderOnly 布局、对比度和控件边界断言；默认和最小支持尺寸均为 1360×900。可见输入框、静态按钮和频道卡动态按钮的实测边界没有相互重叠。
- 左右外卡片实测各宽 654 px，差值为 0 px。`SerialBox` 与连接/断开按钮均高 29 px，底边都在 y=521；加入监听按钮与频道 ID、类型输入框均高 29 px，底边都在 y=532。
- CAT 模式和频率输入分别宽 139 px、182 px；功率滑块宽 206 px，唯一“应用”按钮位于最右侧。操作结果行位于这些控件下方。标题与 BM 状态行中心 y 均为 27 px。
- 日常控制外卡片以外没有嵌套装饰边框。音频设备选择区位于音量控制上方。频道卡、三行历史、BM 静态组分页与固定窗口区域均保留。
- 主窗口及设置窗口 XAML XML、RenderOnly 涉及的 PowerShell AST 和 UTF-8 BOM 检查均通过。
