# R123 固定 WPF 主窗口布局

## 布局合同

- 主窗口固定为 1360×900，顶部状态和短暂事件在同一行；主区域内不使用区域滚动条。频道卡固定为 3 列 × 2 行；没有分页内容时导航行折叠，不占用卡片高度。
- 来话历史外框固定为 120 px，标题行至少 28 px，列表显示 5 行；分页时每页 5 条，末页可不足 5 条。RenderOnly 已检查 5 条完整显示及 5+3 条分页。
- 下方连接配置和日常控制各占 50%。连接配置保留固定标题、5 个等高设置行和底部操作行；最底部只放 BM 连接切换与保存按钮。连接标题和设备刷新按钮垂直居中对齐。
- 串口设置行包含 Wires-X 端口、CAT 端口、波特率和唯一串口连接切换按钮。CAT 模式、频率、功率等宽排列，输入框同为 29 px 高；功率预设为 5、10、15、25、50 W，唯一“应用”按钮位于功率标题旁。
- 呼号、DMR ID、设备编号，BM 服务器、端口、主机名，以及 API key、密码分别位于后续三行。移除独立断开按钮和静态运行状态控件；CAT 实测值与各自标题紧凑显示。
- 日常控制区保留频道录入、BM 静态组、音频设备和增益区域。频道 ID 可编辑并兼容手输，内置预设使用 `460997|private`、`46001|group`、`91|group`。静态组区域固定占位；无 API key 时列表上覆盖“需启用BM API key”，实际启用状态由运行时门控。
- 音频设备和增益区固定布局；增益当前值紧邻对应滑块。移除旧频道状态、临时播放/发送状态及已废弃隐藏控件。

## RenderOnly 实测

在 Windows PowerShell STA 下运行 `tools/test-ui-render.ps1`。本轮通过 1,919 项布局和实际边界断言，并生成两份独立 RenderOnly 截图用于位置稳定性比较。实测结果包括：

- 主窗口输出尺寸为 1360×900；下方区域宽度分别为 654 px，左右相等。
- CAT 三个输入各宽约 206.67 px、高 29 px；标题、当前读值和 Apply 按钮边界没有重叠。
- 历史框高 120 px，五行均完整可见；频道卡共 6 个槽位，非空卡片、来话区、操作区和按钮均在网格/所属卡片范围内，卡片之间没有矩形重叠。
- 无 API key 的渲染状态没有静态组列表项，提示覆盖层与列表大小一致；频道分页行保持隐藏。输入和按钮实际边界无重叠，ComboBox 文字对比度达到 4.5:1。
- UTF-8 BOM、XAML XML 和运行时 PowerShell AST 检查通过；脚本比较两次渲染中固定控件的实际位置。
