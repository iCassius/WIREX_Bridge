# R125 主窗口布局与音量滑块验收

## 布局

- 基线：`c12b50a`；窗口固定为 1360×900；上方频道区保持 3 列 × 2 行；下方两区保持 50:50；主窗口和日常控制不显示滚动条。
- 日常控制标题行固定 21 px；频道输入、BM 静态组、音频设备、音量四区使用等高星形行；各区输入控件行垂直居中，标签与输入框相邻。
- BM 静态组行高为 21/49/24 px；输入框和“添加”按钮外沿与列表左右边界对齐；49 px 列表在合成三项测试中完整显示三行。
- 频道标题行高为 24 px；无固定高度限制的中文标题测量值不超过实际高度；长中文频道名使用省略号并在 Tooltip 保留全文；频道卡保持 109 px。

## 音量和资料链接

- 播放与发送增益均为整数 1–16；刻度间隔、方向键步进和翻页步进均为 1；滑块吸附到整数刻度。
- RenderOnly 在 1x、8x、16x 各生成两张 1360×900 截图；像素检查确认 8x/16x 蓝色填充延伸到白色旋钮左缘，旋钮右侧没有蓝色溢出；1x 没有蓝色增益填充。
- 中文来话短呼号和长呼号的模拟点击均由 `OpenUri` 钩子捕获：呼号链接指向 QRZ，DMR ID 链接指向 BrandMeister 资料页；测试没有打开浏览器或请求网络。

## 验证

- Windows PowerShell 5.1 STA：`tools/test-ui-render.ps1` 通过 6,155 项布局、边界和图像断言；六张主窗口截图均为 1360×900。
- 测试覆盖实际 1360×900 截图、重复渲染位置、四个日常控制区等高、BM 静态组添加行对齐、三项列表可见、中文标题自然高度、中文来话名，以及 1x/8x/16x 增益衔接。
- 渲染使用隔离目录和合成数据；未连接 BrandMeister、串口、HRI、音频设备或射频路径；未执行 PTT；未读取用户配置。
- 在当前 Windows DPI 环境完成渲染；未调整系统缩放或验证其他 DPI 档位。
