# R126 中英文界面

## 配置

`config.json` 根对象的 `ui.language` 保存界面语言，只接受 `zh-CN` 和 `en-US`。缺少该字段时按 `zh-CN` 显示。正常配置保存会保留旧文件中缺少的字段；用户点击右上角语言按钮时，程序只更新 `ui.language`，并保留未知配置字段。

中文界面的切换按钮显示 `English`；英文界面的切换按钮显示 `中文`。界面切换会立即重绘当前窗口和已打开的设置窗口，不保存未提交的连接输入，也不启动连接、重连、CAT、BM 或控制命令。

## 翻译边界

静态控件按各自的中文源文案翻译。运行状态由对应状态更新函数以规范源文案重绘；程序不通过反查英文文本恢复中文。下拉项保留稳定的 `Tag` 值，界面只更换显示文本。

用户呼号、姓名、自定义频道名、设备友好名称和协议字段值按原文显示。队列、来话历史、BM/CAT 状态及操作结果可随当前语言即时更新。

CAT 串口项切换语言时，已编辑的端口文本、当前选项和文本选择范围都保留。没有手动编辑的已选端口仍从 `Tag.Value` 读取；测试覆盖选择 COM11 后切换文案，以及在 COM11 项上输入 COM99 后切换中英文和刷新合成设备目录。

## 离线验收

运行 `powershell.exe -NoLogo -NoProfile -STA -File .\tools\test-ui-localization.ps1`，检查语言往返、配置写入范围、未保存输入、下拉 `Tag`、CAT 手动输入、频道和 PTT 目标、排队请求与控制发送计数，并导出 1360×900 英文主窗口截图。WinPS 5.1 STA 本轮通过 81 项断言。测试使用隔离配置、真实 XAML 窗口和合成状态，不连接真实设备或服务。
