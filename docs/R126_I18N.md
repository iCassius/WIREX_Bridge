# R126 中英文界面（第10项暂缓）

第10项中英文切换暂缓，不计入本轮交付。主窗口固定使用简体中文，语言按钮隐藏、禁用且没有点击事件。以下翻译基础设施和 CAT 编辑保护实现仍保留，供后续启用切换时复用。

## 配置

配置模块仍接受 `ui.language` 的 `zh-CN` 和 `en-US` 值，并会在普通配置保存时保留该字段。当前界面启动固定为 `zh-CN`，不应用、不覆盖配置文件里已有的 `ui.language` 值；用户不能从主界面切换语言。

`UiLocalization.psm1` 的词典、窗口重绘函数及 CAT caption 更新代码保留。CAT 手动输入和选区在选项 caption 更新期间保留；设备刷新后 getter 仍返回手动输入值。

## 翻译边界

静态控件按各自的中文源文案翻译。运行状态由对应状态更新函数以规范源文案重绘；程序不通过反查英文文本恢复中文。下拉项保留稳定的 `Tag` 值，界面只更换显示文本。

用户呼号、姓名、自定义频道名、设备友好名称和协议字段值按原文显示。队列、来话历史、BM/CAT 状态及操作结果可随当前语言即时更新。

CAT 串口项切换语言时，已编辑的端口文本、当前选项和文本选择范围都保留。没有手动编辑的已选端口仍从 `Tag.Value` 读取；测试覆盖选择 COM11 后切换文案，以及在 COM11 项上输入 COM99 后切换中英文和刷新合成设备目录。

## 离线验收

运行 `powershell.exe -NoLogo -NoProfile -STA -File .\tools\test-ui-localization.ps1`，本轮通过 81 项断言。测试使用隔离的 `ui.language=en-US` 配置，检查程序仍以中文启动、语言按钮隐藏且点击不切换、不改配置，并导出 1360×900 中文 RenderOnly 截图；同时验证本地化词典函数和 CAT COM99 输入在合成设备刷新后仍可读取。该测试不验收用户可用的英文界面；不连接真实设备或服务。
