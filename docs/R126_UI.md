# R126 UI 调整与验收

## 范围

在 `2d8b7ea65f4375ba12def61c314bc28087e75518` 的主窗口视觉调整基础上，本轮继续保留布局与 CAT 可编辑串口输入修复。第10项中英文切换暂缓：运行界面固定中文，按钮隐藏并禁用，没有点击绑定；翻译模块保留供后续使用，不计入本轮功能验收。离线测试使用真实 WPF XAML 窗口和合成设备数据；没有执行 Git 操作，也没有连接真实电台、BM 服务或 PTT。

## 界面调整

- BrandMeister 静态组列表在刷新忙碌、列表禁用时使用暗色列表项模板；禁用文字为灰色，列表项文字显式继承 `ListBoxItem.Foreground`。BM API 缺失时仍由原遮罩显示提示。
- 静态组输入框在左、按钮在右，中间留 6px；按钮显示“添加为静态组”。动态频道 ID 标签显示“增加动态组 频道ID”，静态组区标签显示“增加BM静态组”。
- 连接配置和日常控制的字段标签字号从 10 调到 11；组合框默认字号从 13 调到 14，波特率组合框从 11 调到 12。设备刷新按钮宽度增加到 104，以容纳“Refresh devices”测试文案。
- 连接配置的五个设置行使用相同上下间距。连接BM和保存配置按钮上方对齐，固定 52px 底行在按钮下方留出空间。
- 隐藏重复的 MAIN 观测模式文字，同时保留命名控件和文本更新。RenderOnly 将模式读数设为 `FM`，布局证据确认控件隐藏且仍收到该读数。
- CAT 手动输入及输入框选择范围在设备选项 caption 更新期间保留，设备刷新后 getter 仍读取用户手动输入的 COM99。
- 主窗口不展示语言切换按钮，启动时固定中文且不改写配置中保存的 `ui.language`；语言词典和翻译调用保留，但第10项切换功能暂缓。详见 [R126_I18N.md](R126_I18N.md)。
- 主窗口仍固定为 1360×900，下方两列各占 50%，频道区域为 3×2，主界面区域没有滚动条。
- RenderOnly 在最终频道卡片重建后同时采集截图和实际边界，避免截图与 `layout-info.json` 来自不同的 WPF 控件实例。

## 验收

执行命令：

```powershell
powershell.exe -NoLogo -NoProfile -STA -File .\tools\test-ui-render.ps1
```

结果：通过，共 6,404 项布局与实际边界断言；覆盖音量档位 1/8/16、BM API 缺失、三条静态组刷新忙碌态、英文长文案和 1360×900 RenderOnly 截图。测试还检查了静态组三行的实际 WPF 前景色、背景色和边界，并确认隐藏的 MAIN 控件仍保留 `FM` 读数。

`powershell.exe -NoLogo -NoProfile -STA -File .\tools\test-ui-localization.ps1` 通过 81 项断言；检查应用在隔离 `ui.language=en-US` 配置下仍启动为中文、按钮隐藏禁用且点击不改语言或配置，并验证 COM99 在同语言 caption 更新和合成设备刷新后仍由 getter 返回。RenderOnly 截图使用中文界面；词典函数检查只证明翻译实现仍保留，不作为英文界面交付验收。

`powershell.exe -NoLogo -NoProfile -STA -File .\tools\test-ui-console.ps1` 先前通过 121 项真实 WPF 断言；使用 `PART_EditableTextBox` 和键盘焦点编辑 CAT 端口，无全局按键注入。该结果早于本次第10项暂缓开关调整。

已目视检查 `bm-static-groups-disabled-busy.png`、`bm-static-groups-english-long-copy.png` 和 RenderOnly `main-window.png`。三条禁用静态组文字呈灰色，刷新与添加长文案完整可读，英文长文案没有遮挡控制项。截图与 `layout-info.json` 保存在本次测试创建的系统临时目录中；RenderOnly 实际边界断言也验证了按钮次序、4–8px静态组输入间距、底部留白以及固定窗口分区。

本次结果属于离线 UI、配置范围和实际 WPF 布局证据；没有进行真实设备端口读写、BM 网络、音频、PTT 或 RF 验收。RenderOnly 截图及 `layout-info.json` 位于测试创建的系统临时目录中。
