## 读取范围

观察器每 100 ms 读取 `HRI_UART.dll` 的 `DAT_10191d38` 两个表项，并分别记录每个实例的：

- `+0x50`、`+0x58`、`+0x1d4`、`+0x1dc` 与 `+0x28f8` 原始数值；这些字段不解释为 Node Mode 或实例业务类型。
- 子对象 vtable 地址/RVA、record context 指针及其 `+0x10` 原始 DWORD、现有 `+0x14` factory 路径的 vtable 方法地址/RVA。
- 根据 `+0x28f8` 静态候选分支读取的回调指针，以及对应的 RigDataIf 队列计数；同时列出两个队列的计数和 head 是否为空，不解引用队列 head。
- 对实例 `+0x1420` 起始的 header 逐字节计数到首个 NUL，最多读 512 字节；只输出长度、扫描数量和读取状态，不保留或输出 header 正文。

任一表项为空或无法读取时，另一表项仍单独记录。观察器不挂钩函数、不调用导出函数或目标代码、不写内存，最多运行 10 秒，变化事件最多输出 16 条。

## 离线验证

运行 `node tools/research/r91_hri_dual_instance_metadata_observer_offline_test.js` 可在 VM 合成内存中验证双表项、字段范围与队列分支、无效表项隔离、读取边界、10 秒限制以及无 hook/调用/写入。该测试没有启动或附加目标程序。

R91 仍是未执行的只读观察工具。它不确认两个实例分别对应什么业务类型，也不将原始字段解释为 LCD、RF 或媒体协议状态。
