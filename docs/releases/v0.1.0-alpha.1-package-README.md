# WIREX Bridge v0.1.0-alpha.1

## 准备连接

1. 用 USB 连接 FTX-1，将 HRI Mode 设为 `ON`、Node Mode 设为 `DIRECT`，并关闭官方 WIRES-X 程序。
2. 首次使用自己的 BM 身份时，运行 `start-profile.cmd`，填写 BM 呼号、Gateway ID、Source ID、Master、目标、时隙、Color Code 和通话类型。profile 保存非秘密连接参数。
3. 在本机 `private\bm-device-password.txt` 中单独保存 BM 密码；若没有该文件，程序会在控制台隐藏提示输入。
4. 等待电台与 BM 均就绪后，松开一次手咪 PTT。按住 PTT 讲话，松开后结束本次上行；按 `Q` 停止程序并退出。

## 使用固定预设

固定预设是原作者测试身份 `BI7KGD` 的快捷入口，仅用于该身份和对应的 BM 密码：

- `start-bm-radio-bridge.cmd`：连接 BM 鹦鹉单呼目标 `parrot-cn`。听到回声仅适用于此鹦鹉单呼测试。
- `start-listen-91.cmd`：接收 TG91。测试身份需先在 BM SelfCare 为 Gateway `461135501` 的 TS2 配置 TG91 静态订阅。
- `start-bm-radio-bridge.cmd -Preset listen-46001`：只接收 TG46001 组呼。

其他用户请使用 `start-profile.cmd` 配置自己的 BM 身份、Gateway 和订阅。

## 调整声音

电台回放增益默认 `1.0x`，手咪上行增益默认 `16.0x`。可用 `-RadioPlaybackGain` 和 `-MicTransmitGain` 调整；每项分别保存在本机 `audio-settings.json`。

密码、profile、音量设置和运行日志保留在本机，不要发送给他人。

## 下载文件

先从该版本的 GitHub Release 页面单独下载 `download-release.ps1`。在下载脚本所在目录运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\download-release.ps1 -Tag v0.1.0-alpha.1 -Destination C:\WIREX-Bridge-v0.1.0-alpha.1
```

脚本会从该 Release 下载文件，按 `manifest.json` 校验并还原便携目录。随后从还原出的目录启动程序。
