# WIREX Bridge v0.1.0-alpha.1

> 私有 alpha 预发布。源码提交、构建记录、文件清单和各文件 SHA-256 随本版本提供；请以本 Release 的 `manifest.json` 和 asset 列表为准。本 alpha 的最终电台与 BM 联合 HIL 仍待完成。

## 本版内容

本 alpha 面向 FTX-1 DIRECT 个人终端，将 HRI 串口和 USB 音频接入 BrandMeister：

- HRI 与 BM 会话就绪后，由物理手咪 PTT 驱动 BM 上行；松开手咪结束本次上行。
- 将 BM 下行语音播放到电台扬声器。
- 提供 `parrot-cn` 鹦鹉单呼，以及 `listen-91`、`listen-46001` 只收预设；46001 组呼严格禁止上行。
- 分别调节手咪上行和电台回放 PCM 增益；连接 profile 只保存非秘密字段，BM 密码单独存放或通过隐藏提示输入。
- 以前台控制台运行；空闲时持续等待，单次通话最长 120 秒，按 `Q` 停止并退出。

## 开始使用

首次使用自己的 BM 身份时，运行 `start-profile.cmd` 并填写连接参数。连接 FTX-1 USB，设 HRI Mode `ON`、Node Mode `DIRECT`，关闭官方 WIRES-X 程序；连接就绪后松开一次 PTT，再按住手咪讲话，松开后结束上行。只在 `parrot-cn` 鹦鹉单呼测试中等待回声。固定预设是原作者测试身份 `BI7KGD` 的快捷入口；TG91 收听还需要在该测试 Gateway 的 TS2 配置静态订阅。详情见[包内操作说明](v0.1.0-alpha.1-package-README.md)。

## 验证记录

- 当前源代码的正式 clean build 运行了 27 项离线测试，全部通过；这些测试不验证这版包的电台声音或 RF 行为。
- 用户曾分别确认 `005c5e8` 版本的一次 DIRECT→BM 鹦鹉回声，以及 `ab3c5fa` 版本的 TG91 实机收听。这两项是各自历史版本的结果，不是本 alpha 的 HIL 结果。
- 本 alpha 的最终包尚未进行电台与 BM 联合 HIL。测试计划和验收核对项见[首个 Release 验收清单](https://github.com/iCassius/WIREX_Bridge/blob/v0.1.0-alpha.1/docs/首个Release验收.md)。
- FTX-1 LCD 上显示 BM 当前呼号/房间、DIRECT 运行期间的 RF 接收路由、BM 到 RF 发射和图形 UI 不属于本 alpha 已实现范围。`Q` 收尾和程序报告不会确认电台侧 PTT 或 RF 状态。

## 发布文件

对应 Tag 保存完整源码和构建脚本。Release 页面以独立 asset 提供便携运行文件和 `download-release.ps1`；`manifest.json` 映射包内相对路径并记录逐文件 SHA-256，下载脚本会校验文件并还原便携目录。Release 页面显示的提交号和文件摘要用于核对下载内容。

仓库包含第三方 DMR 信令与 MBE/IMBE 实现及相应许可材料。随版本提供的 `licenses/` 文件、对应源码和固定上游版本信息由验收清单核对；本说明不为项目补选新的全局许可证。
