# WIREX Bridge v0.1.0-alpha.10

## 启动与本机设置

双击包根目录唯一的 `start-wirex-bridge.cmd`。连接、音量、频道收藏、RadioID 缓存和密码路径保存在本机用户配置目录。默认目录为包内 `private/user-config`；需要多个版本共用设置时，可在本机另建 `private/user-config-directory.txt`，写入一行 canonical `UserConfigDirectory` 绝对路径。个人指针和配置文件不包含在通用发行包中。

## 当前功能

收到有效来话 ID 后先显示数字 DMR ID，再在后台查询单条 RadioID 资料。网络超时或未命中时仍显示数字 ID；已有本机缓存时使用缓存资料。主窗口仅在核心报告相应数据后显示 BM 往返、DMRD 丢包百分比、接收队列和已有的播放增益/削波数据。alpha.10 没有改动 DSP、音频排程或现有语音路径。

FTX-1 LCD 呼号显示和 FM/C4FM RF 发射路径尚未实现。

## 验证范围

本候选经过离线脚本、UI RenderOnly 样例和本机 HTTP 查询夹具检查；没有向真实 RadioID 或 BM 发起请求，没有连接 COM、真实音频设备，没有触发 PTT 或 RF。
