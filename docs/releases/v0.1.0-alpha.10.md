# WIREX Bridge v0.1.0-alpha.10

alpha.10 集成 R112-A 来话身份自动查询与退出收尾、BM 往返时间和 DMRD 接收指标，以及单页界面精简。有效来话先显示 DMR ID，再在后台查询单条 RadioID 资料；超时或未命中时保留数字 ID。界面显示核心实际报告的 BM RTT、DMRD 丢包百分比、接收队列和已有音频增益/削波数据，没有样本时收起对应行。

本版没有修改 DSP、音频排程或现有语音路径。FTX-1 LCD 呼号显示与 FM/C4FM RF 发射链尚未实现。RenderOnly 预览和本机 HTTP 查询夹具只覆盖离线界面与查询收尾，不连接真实 BM、RadioID、COM 或音频设备。

alpha.10 仍为本机候选交付；本说明不表示 Git tag 或 GitHub Release 已创建。
