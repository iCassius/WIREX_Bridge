# WIREX Bridge v0.1.0-alpha.10

alpha10 集成来话 DMR ID 后台 RadioID 查询、BM 客户端往返时间估计、DMRD 序号缺包和主窗口数据精简。来话先显示数字 DMR ID，再异步查询单条资料；查询等待最多 5 秒，超时或未命中时保留数字 ID，查询不会停止音频。界面只展示核心实际报告的数据和已经实现的操作；没有样本时收起对应指标行。

构建来源是干净提交 e234a55aeff6fe2cff1985ef47fc4d94378ab474。clean full39 的 39 项离线测试通过，编译警告和错误为 0。根审通过的本机测试包位于 build/releases/v0.1.0-alpha.10，当前有 34 个文件，其中 32 项由 manifest 映射。最终 manifest SHA-256 为 2774f3a956e6c4bdf1dd639be41a6ffd1c1935d8a342767807ccc58971daf8c1。manifest 外的本机 user-config-directory.txt 指向现有用户配置目录。

Windows PowerShell 5.1 包启动检查和 Native test-control 的隔离检查均通过。它们没有连接真实 BrandMeister、COM、音频设备或电台。alpha10 没有进行硬件验收。FTX-1 LCD 呼号显示、FM RF 发射和 C4FM RF 发射链仍未实现；alpha9 闪退根因仍未确认。

alpha10 目前是根审通过的本机测试包；没有创建 Git tag、ZIP 或 GitHub Release。本说明的 Git 提交晚于 e234 构建，本文不在 alpha10 manifest 内。
