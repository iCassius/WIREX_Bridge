# WIREX Bridge v0.1.0-alpha.11

## 启动和本机资料

双击包根目录唯一的 `start-wirex-bridge.cmd`。连接、音量、频道收藏、RadioID 缓存和密码路径保存在本机用户配置目录。默认目录为包内 `private/user-config`；如需多个版本共用设置，可在本机另建 `private/user-config-directory.txt`，其中只写一行 canonical `UserConfigDirectory` 绝对路径。通用发行包不包含个人配置、缓存、收藏、密码或密码路径文件。升级时应让程序沿用已有用户目录，不要用空目录覆盖旧配置。

## R113 来话呼号接线

收到有效 DMR 来话 ID 后，UI 将新鲜 RadioID 资料映射交给 Native 身份缓存。UI 同时只发送一条更新并等待 ACK，单条等待最多 5 秒；待发送队列和跨运行暂存队列各自最多保存 128 个 ID。revision 按本次运行递增，防止旧响应覆盖较新资料。呼号规范化为大写 A–Z、数字和连字符，长度为 1–10 个字符且至少含一个字母。

Native 只在后续 `callStart` 已有缓存资料时，把呼号写入既有 mode 4 T90 的 `SrcCallSign` 十字节字段；没有缓存时仍保留原有数字 ID 标签。已经开始的通话不会收到第二条 T 记录或活动画面的热更新。其它 T90 字节、模式、声路、播放和 PTT 时序不在此改动范围内。

呼号字段已实际接入现有起始记录；真实 LCD 绘制待本轮用户测试。mode 4 的正式 LCD 显示语义也未获证实；本候选不会把 Native 的发送记录或 UI 状态显示成屏显成功，也不会为 LCD 未知状态增加界面卡片。FM 和 C4FM RF 发射未实现，UI 没有这些功能入口。

## 验证边界

呼号字段已接入现有起始记录，真实 LCD 绘制待用户直接观察确认。Native 的完整帧写出记录、UI 状态和离线软件测试均不作为电台屏幕显示证据。本版本没有 FM/C4FM RF 发射入口，也不声称真实 COM、音频、BrandMeister、PTT 或 RF 已通过设备验证。
