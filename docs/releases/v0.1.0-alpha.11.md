# WIREX Bridge v0.1.0-alpha.11 本机候选

alpha11 候选接入 R113 LCD 元数据路径：UI 将新鲜 RadioID 映射通过专用 `radio_identity.cache_upsert` 消息送入 Native 身份缓存；UI 同时只发送一条更新并等待 ACK，单条等待最多 5 秒，待发送和跨运行暂存队列各自最多保存 128 个 ID。后续 `callStart` 只有在缓存命中时，才在原有 mode 4 T90 `SrcCallSign` 字段中写规范化呼号。无缓存时继续使用原有数字 ID 标签。已经开始的通话不会收到第二条 T 记录或活动显示热更新。

此次功能没有更改其它 T90 字节、工作模式、声路、播放或 PTT 时序。RadioID 查询和音频指标行为沿用 alpha10。本版本不接入 FM/C4FM RF 发射入口。

呼号字段已实际接入现有起始记录；真实 LCD 绘制待本轮用户测试。mode 4 的正式 LCD 语义尚未证实；Native 写出记录只能说明程序提交了完整记录，不能作为屏幕显示结果。UI 不显示 LCD 成功或未知卡片。

## 验收边界

本文记录本机候选的功能范围，不包含具体构建散列或包目录。独立的本机交接记录维护构建、包级检查和审查结果。呼号字段已接入现有起始记录；真实 LCD 绘制仍待用户目视确认，本文不作为设备验收凭据。未创建 Git tag、ZIP 或 GitHub Release。
