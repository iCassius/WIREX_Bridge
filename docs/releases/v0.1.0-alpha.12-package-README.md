# WIREX Bridge v0.1.0-alpha.12

## 启动和本机资料

双击包根目录唯一的 start-wirex-bridge.cmd。连接、音量、频道收藏、RadioID 缓存、密码路径和电台控制偏好留在本机用户配置目录。没有个人目录指针时，默认目录是包内 private/user-config；如需多个版本共用配置，可在本机建立 private/user-config-directory.txt，其中只写一行 canonical UserConfigDirectory 绝对路径。

电台控制偏好文件名为 radio-control-preferences.json，只保存在本机用户配置目录。首次打开设置窗不会创建偏好文件；用户选择“保存设置”时才保存。初始期望功率是 25 W；初始串口偏好为 COM11、38400 波特、8 数据位、2 停止位。如果 Windows 没有枚举出 COM11，界面会标示该已保存端口当前不可用，不会伪造设备项。应用启动、读取 CAT 状态或保存偏好时都不会因 25 W 期望值自动发写命令。通用发行包不包含个人配置、RadioID 缓存、收藏、密码或密码路径，也不包含该偏好文件。

## FTX-1 CAT-1 控制

RadioCat 为用户提供一次一项的 CAT 查询或设置：查询机型、发送状态、MAIN/SUB 频率、无线机模式与功率控制值；设置 MAIN 频率、无线机模式和功率控制值。无线机模式选项分列 FM、FM-N、C4FM-DN、C4FM-VW。CAT 手册没有说明 HRI 语音实际使用 DN 还是 VW，因此读回的模式只说明无线机当前 CAT 模式。

每项操作都会打开短时 CAT-1 会话、读取并核对机型 ID 0840。写操作还会读取发送状态，只有读到 TX0 才继续；程序最多写一次，随后必须读回匹配的值。失败时不自动重试。设置 MAIN 频率或模式时，UI 会先停止 Bridge 核心，并在完成后保持断开，不自动重连。应用功率时，UI 还要求最近 3 秒内状态为空闲、没有当前通话、接收媒体空闲或已过滤、接收队列为空；CAT 模块随后重新核对 ID/TX 状态。功率控制值来自本次 CAT 读数的路径：Field Head 路径限 5–10 W，SPA-1 路径由应用限 5–50 W。PC 读数是无线机功率设置，不是天线端的射频功率测量。

FTX-1 的 HRI MODE 开关和 WIRES-X Node Mode 没有公开 CAT/EX 命令，本版本不提供这两项开关，也不会猜测 EX 菜单地址。进入 WIRES-X HRI 仍需按官方面板流程操作。RadioCat 不发送 TX/PTT、EX 菜单、AI 设置或发射命令。

## 来话身份与 LCD 实验

alpha.11 已接入的 RadioID 映射仍供后续 callStart 使用：Native 只会在已有来话记录的 mode-4 T90 SrcCallSign 十字节字段中写入缓存呼号。这个字段写出不能证明 FTX-1 LCD 实际显示该呼号。

FTX-1 LCD 本轮仅作实验研究，不作为 alpha.12 主线功能。用户在 DIRECT/HRI 环境观察到没有来话或列表内容、底部软键无响应，红色指示灯行为与 Bridge 环境相同；这些观察不用于推断红灯的底层原因。alpha.12 不显示 LCD 成功卡片，也不宣称 Native 发帧等于屏幕已更新。R112 网络音频指标和 R113 历史文档仍在包内，供既有功能与接线背景查阅。

本版本不实现 FM 或 C4FM RF 发射入口。
