# WIREX Bridge v0.1.0-alpha.13

Alpha 13 本机测试版增加 BrandMeister 服务器选择、电台设备选择和静态组管理，并保留 DIRECT 桥接与 R116 CAT 控制。

## 连接与电台

服务器列表默认选择 BM China 4602（`4602.master.brandmeister.network:62031`）；沿用现有 `43.129.83.124:62031` 连接值。也可以手工填写服务器地址和端口。程序启动后自动识别可用 COM 口，并读取电台状态；修改 CAT 设置后，点击“应用”才会写入电台。

连接期间，左侧连接配置保持锁定；右侧提供组控制、收听、发射、音量和功率操作。

## 组控制与静态组

- **本机收听**：设置本机允许或屏蔽接收的组。
- **动态组激活**：发起一次 Quick Call，建立临时动态组通话会话。
- **BM 静态组**：读取并管理 BrandMeister 服务器保存的设备订阅组。

静态组管理需要在连接配置中选择 BM API v2 密钥文件。程序仅将密钥文件路径和界面偏好保存在本机的 `bm-management-preferences.json`；密钥内容保留在所选文件中。添加或移除静态组后，程序会重新读取列表确认结果。

## 本机数据

连接 profile、音频设置和界面偏好保存在本机配置目录，不随通用发行包分发。BM 服务器选择仅在你保存后写入本机 `bm-server-preferences.json`；打开窗口不会自动写入。API 密钥文件保留在你选择的位置。
