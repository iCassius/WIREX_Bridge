## 本版内容

- 增加离线 BrandMeister 服务器列表，BM China 4602 排在首位；选择 4602 沿用当前 profile 的 `43.129.83.124:62031`。仍可手工填写服务器与端口。
- 分开识别串口设备与音频设备；保留可识别的 HRI/CAT 设备选择，并允许手工选择未识别的 COM 口。
- CAT 控制沿用 R116 查询与读回流程，写入前查询电台状态，写入后核对返回状态。
- 增加 BM 静态组列表、添加和移除操作。操作使用 `connection.gateway_id` 作为设备号、本机选择的 BM API v2 密钥文件，并在每次写入后重新读取列表。
- 明确区分本机收听规则、动态组临时激活和 BM 服务器静态订阅。
- Alpha 13 profile 保留 Alpha 12 的 40 项 Native 测试名称和顺序，没有增加 Native 测试项。
