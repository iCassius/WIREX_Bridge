# WIREX Bridge v0.1.0-alpha.14 本机测试版记录

状态：R118/alpha14 源码范围已冻结；尚待新源码提交后的 Native clean build 和本机发行目录包验收。

## 计划内容

- 将连接身份、BM Master、密码和 API Key、设备、音频、频道、发送目标及界面设置集中保存到发行文件夹根目录的 `config.json`。
- 通过设置界面直接输入 BM 密码和 API Key，不再要求新的凭据路径文件。
- 移动整个发行文件夹时，配置随程序目录移动。
- 继承 alpha13 运行资产并加入 `ui/windows/PortableConfig.psm1`。
- 保持 alpha13 的 40 项 Native 测试清单和顺序。

## 本次发布准备边界

alpha14 启动器默认把自身所在的发行文件夹作为 `packageRoot`，并让 UI 从 `packageRoot/config.json` 读取配置。默认启动不读取旧版 `private/user-config-directory.txt`，也不传入 `UserConfigDirectory`。隔离的 `PrepareOnly` 和 `RoutingDiagnosticAutoTest` 入口仅用于包级检查；它们不得连接真实 BM、打开 COM、启动 PTT 或发射。

通用包采用固定 asset allowlist。manifest 显式列出 `config.json`、`config.*.backup*`、`credentials/`、`tempSecrets/` 和遗留个人偏好为排除项；构建器不会复制这些文件或目录。

配置/BM、发布工具与五项真实 WPF 回归已通过双 PowerShell 自动化检查；具体证据见 [R118 发布交接](../R118_发布交接.md)。当前没有迁移个人配置、读取真实密码/API Key、连接 BM、打开串口、启动音频/PTT/RF、构建 Native 程序或生成本机包。Native build 和包级验证等待源码提交后执行；root 完成包审计前不标记 root_audit_passed。
