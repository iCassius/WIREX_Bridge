# WIREX Bridge v0.1.0-alpha.15 本机候选记录

状态：R119 源码已冻结；fresh Native 构建和本机文件夹包正在本轮生成。包生成后将保持 `awaiting_root_audit`，等待 root 独立审计。此版本不是 ZIP、Git tag 或 GitHub Release。

## R119 内容

- CAT 在 HRI 连接成功后执行首次全状态查询，再按周期同步 MAIN/SUB 频率、模式和功率观测。周期查询期间编辑器与滑块保持稳定，用户草稿不被读回覆盖；查询与 Apply 操作仍由一个 worker 串行门控。断连会撤销设置授权并保留可见观测值，重连清理旧 worker 后须重新查询再允许设置。
- 电台控制标题旁显示现有 CAT readback，不新增重复的观测数据源。离线 WPF 测试使用 fake CAT worker，不访问真实 COM。
- 播放和麦克风增益运行中控制受 `audio.gains.set` 能力门控。alpha14 的旧能力命令集仍可启动，且继续使用启动配置的固定增益；新 Native 才启用运行中热调和 readback。Supervisor 只接受此精确命令及对象参数，并限制完整请求不超过 4096 字节。
- Generic 包沿用 alpha14 的运行时资产路径、目录和 Native 40 项测试顺序。alpha15 只替换既有包内 README 和唯一启动器；清单预计仍为 41 个资产，加 manifest 共 42 个通用文件。个人 `config.json`、备份、credentials 与 tempSecrets 不纳入包。

## 源码与验证边界

R119 的 status、identity、lifecycle、radio-cat、console 五项 WPF 回归已在 PowerShell 7.6.5 STA 与 Windows PowerShell 5.1 STA 通过。`test-ui-console.ps1` 每版通过 120 项真实 WPF 交互断言。较早完成的离线 package/publish/download 合成测试分别通过 606/127/2307 项；包内音量能力和真实 IPC 边界仍须使用本轮候选包运行 `test-package-startup.ps1` 复验。

本轮不读取、复制或修改个人配置，不更改根目录启动器，不连接真实 BrandMeister、COM/HRI、音频设备，不触发 PTT/RF。包内动态控制验收使用候选 Native 的 routing diagnostic 内存 sink。
