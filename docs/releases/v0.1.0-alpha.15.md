## R119 内容

- CAT 在 HRI 连接成功后执行首次全状态查询，再按周期同步 MAIN/SUB 频率、模式和功率观测。周期查询期间编辑器与滑块保持稳定，用户草稿不被读回覆盖；查询与 Apply 操作仍由一个 worker 串行门控。断连会撤销设置授权并保留可见观测值，重连清理旧 worker 后须重新查询再允许设置。
- 电台控制标题旁显示现有 CAT readback，不新增重复的观测数据源。离线 WPF 测试使用 fake CAT worker，不访问真实 COM。
- 播放和麦克风增益运行中控制受 `audio.gains.set` 能力门控。alpha14 的旧能力命令集仍可启动，且继续使用启动配置的固定增益；新 Native 才启用运行中热调和 readback。Supervisor 只接受此精确命令及对象参数，并限制完整请求不超过 4096 字节。
- Generic 包沿用 alpha14 的运行时资产路径、目录和 Native 40 项测试顺序。alpha15 只替换既有包内 README 和唯一启动器；实包有41条资产记录、37项源码映射，加 manifest 共42个通用文件。个人 `config.json`、备份、credentials 与 tempSecrets 不纳入包。

通用包生成和包级验收没有读取个人配置。root 审计通过后，当前 alpha14 `config.json` 原字节复制为 alpha15 本机覆盖文件，并通过 source `PortableConfig.psm1` 只读校验；根目录启动器备份后改为相对调用 alpha15 唯一 CMD，正常启动未运行。没有读取或迁移 legacy canonical，没有连接真实 BrandMeister、COM/HRI、音频设备，也没有触发 PTT/RF。包内动态控制验收使用候选 Native 的 routing diagnostic 内存 sink。
