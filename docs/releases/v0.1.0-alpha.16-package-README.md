# WIREX Bridge v0.1.0-alpha.16

这是 Windows 本机测试版。双击发行文件夹根目录的 `start-wirex-bridge.cmd` 打开控制台。

## 设置与移动

所有连接、凭据、设备、音频、频道和窗口设置保存在发行文件夹根目录的 `config.json`。首次启动只读取默认值，不会自动创建配置文件。点击“保存配置”或连接时保存设置后，程序会创建 `config.json`。移动软件时，请移动整个文件夹；`config.json` 会与启动器和程序一起移动。

BM 密码和 API Key 可直接在设置界面输入，不需要单独的凭据文件。两项会随其它设置写入 `config.json`。此文件是普通 JSON，不加密；请按包含凭据的文件妥善保管，不要放进公开共享目录。

Generic 测试包不包含用户的 `config.json`、配置备份、`credentials` 或 `tempSecrets` 目录。每个用户应在自己的发行文件夹中填写设置。

## 连接、电台和音量

- 在连接设置中填写呼号、Gateway ID、Source ID、BrandMeister Master、UDP 端口和色码，并选择需要的 HRI 设备。
- 使用 DIRECT/WIRES-X HRI 桥接时，选择实际连接的 HRI 串口；音频端点和播放/麦克风增益也保存在同一配置中。
- CAT 控制使用单独的 CAT 串口和波特率设置。停止位固定为 Two；界面不提供停止位选择。连接 HRI 后会读取并周期同步电台 MAIN 模式、频率和发射功率；读取期间编辑器保持可用。
- Alpha.16 沿用既有 Native 的 `audio.gains.set` 能力。若当前 Native 广告该能力，连接后可调整播放和麦克风增益，界面以 Native 回读确认运行值；不广告该能力时，程序保留保存的启动增益，不发送热调命令。
- 频道列表按显示顺序保存，组呼或私呼频道可用于收听或作为起呼频道。手动保存的合法频道 ID 范围为 1 到 16,777,215；ID 91 和 46001 不会仅因号码自动禁发。选择起呼频道后，按手咪 PTT 发射。仅选择频道不会自动发射。
- 收听列表、发送目标和 BM 静态订阅分别管理。改变本地频道列表不会自动修改 BM 静态组订阅。

## BrandMeister 静态组

- 刷新会从 BM 静态组列表接口读取当前订阅。列表行只显示 TG 数字；移除时使用 BM 返回记录中的原时隙。
- 添加时应用读取 BM 设备状态：status 4 使用 API slot 0；status 0–3 使用当前桥接的网络 slot 2。设备状态缺失或无效时，列表仍可查看，但添加按钮禁用。
- Add 和 Remove 仍需要已配置的 BM API Key。应用不会用 BM 账户密码模拟网页登录。

第一次连接前请核对电台模式、串口、音频设备、呼号和 DMR ID。自动测试不包含实机 CAT/HRI、音频、BM、PTT 或 RF 验收结果。
