## R120 内容

R120 将监听频道显示为 3 列 × 2 行固定卡片，超过六个频道通过页码翻页；呼入身份显示 DMR ID，解析合法呼号后才提供 BM profile 链接。用户界面不显示时隙选择，现有 Native/config slot 保持原义。BM 连接状态和 RTT 位于应用标题行，CAT 串口端口及连接/断开位于电台控制区。

CAT 串口会话与 Wires-X supervisor 分离。普通 CAT 查询不阻止保存 BM 配置或启动 Wires-X；CAT 显式写入、排队动作以及等待 mode/frequency 写入的请求会短暂阻止新核心启动。Wires-X 最终候选 COM 与仍由 CAT 占用或正在收尾的端口相同时，本次启动会被拒绝，CAT 会话保留。BM 静态组列表继续使用既有 API 路径；添加依据设备状态选 API slot，移除按列表原始 slot 操作。
