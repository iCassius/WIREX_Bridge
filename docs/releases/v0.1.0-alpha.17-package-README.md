# WIREX Bridge v0.1.0-alpha.17

这是 Windows 本机测试版。双击发行文件夹根目录的 `start-wirex-bridge.cmd` 打开控制台。

## 设置与移动

连接、凭据、设备、音频、频道和窗口设置保存在发行文件夹根目录的 `config.json`。首次启动读取默认值，不自动创建配置文件；保存配置或连接时会创建该文件。移动软件时，请移动整个文件夹。

Generic 测试包不包含用户的 `config.json`、配置备份、`credentials` 或 `tempSecrets` 目录。请在各自的发行文件夹中填写设置，并妥善保管包含 BM 密码或 API Key 的配置文件。

## 控制台布局与连接

- 主窗口使用固定布局，默认尺寸为 1360×900；卡片和历史区域不使用滚动条。历史记录与 BM 静态组列表通过分页查看。
- 点击“连接串口”只连接 Wires-X HRI 与 CAT，BM 保持断开。连接后读取并同步电台 MAIN 模式、频率和功率；点击“连接 BM”后 BM 才入网。
- “断开 BM”会保留 HRI 与 CAT。点击“断开串口”会先断开 BM，再关闭 HRI 与 CAT。“停止并退出”结束整个桥接核心。
- BM RTT 与丢包率只在核心报告有效采样时显示。顶部状态区域集中显示运行事件。

## 电台、频道与 BM 静态组

- 选择需要的 HRI 串口、CAT 串口、音频端点和增益，并填写呼号、Gateway ID、Source ID、BrandMeister Master、UDP 端口和色码。
- CAT 停止位固定为 Two。运行期间可调节音频输入与输出增益。
- 频道可用于收听或作为起呼目标；仅选择频道不会自动发射。改变本地频道列表不会自动修改 BM 静态组订阅。
- BM 静态组按页显示，每行只显示 TG 号码。刷新、添加与移除仍使用 BM API；移除会使用 BM 返回记录中的原时隙。

请在使用前核对电台模式、串口、音频设备、呼号和 DMR ID。自动化检查不包含实机 CAT/HRI、音频、BM、PTT 或 RF 验收结果。
