# WIREX Bridge v0.1.0-alpha.18

这是 Windows 本机测试版。双击发行文件夹根目录的 `start-wirex-bridge.cmd` 打开控制台。

## 设置与移动

连接、凭据、设备、音频、频道和窗口设置保存在发行文件夹根目录的 `config.json`。首次启动读取默认值，不自动创建配置文件；保存配置或连接时会创建该文件。移动软件时，请移动整个文件夹。

Generic 测试包不包含用户的 `config.json`、配置备份、`credentials` 或 `tempSecrets` 目录。请在各自的发行文件夹中填写设置，并妥善保管包含 BM 密码或 API Key 的配置文件。

## 控制台布局与连接

- 主窗口固定为 1360×900，不使用区域滚动条。监听区保留 3 列 × 2 行频道卡片，历史区域显示三条记录并分页。
- 下方连接配置与日常控制各占一半。Wires-X 串口、CAT 串口及波特率集中在连接区；串口选择框与连接/断开按钮同高并对齐底边。
- CAT 区按 MAIN 模式、频率、功率排列。选择“应用”后一次提交三项设置。BM 状态和 RTT 显示在标题行，事件显示在下一行。
- 音频输入、输出设备选择位于右侧日常控制区，音量调节在其下方。频道加入监听、BM 静态组和播放/发送增益均保留。
- 点击“连接串口”只连接 Wires-X HRI 与 CAT，BM 保持断开。点击“连接 BM”后 BM 才连接。“断开 BM”保留 HRI 与 CAT；“断开串口”先断开 BM，再关闭 HRI 与 CAT。“停止并退出”结束整个桥接核心。

## 电台、身份与频道

- 身份区显示呼号、DMR ID 和两位设备编号（00–99）。旧配置能无歧义拆分时显示相应编号；无法无歧义拆分时不猜测编号，未编辑时沿用旧值。
- 呼入历史和频道卡显示现有来话信息。新增频道进入监听列表；呼叫目标在频道卡片单独选择，加入监听不会自动改变呼叫目标。
- 主窗口不提供色码编辑框。现有配置中的色码由程序继续保留。
- BM 静态组按页显示，每行只显示 TG 号码。刷新、添加与移除仍使用 BM API；移除会使用 BM 返回记录中的原时隙。

请在使用前核对电台模式、串口、音频设备、呼号和 DMR ID。自动化检查不包含实机 CAT/HRI、音频、BM、PTT 或 RF 验收结果。
