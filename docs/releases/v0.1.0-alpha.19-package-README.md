# WIREX Bridge v0.1.0-alpha.19

这是 Windows 本机测试版。双击发行文件夹根目录的 `start-wirex-bridge.cmd` 打开控制台。

## 设置与移动

连接、凭据、设备、音频、频道和窗口设置保存在发行文件夹根目录的 `config.json`。首次启动读取默认值，不自动创建配置文件；保存配置或连接时会创建该文件。移动软件时，请移动整个文件夹。

Generic 测试包不包含用户的 `config.json`、配置备份、`credentials` 或 `tempSecrets` 目录。请在各自的发行文件夹中填写设置，并妥善保管包含 BM 密码或 API Key 的配置文件。

## 控制台布局与连接

- 主窗口固定为 1360×900，不使用区域滚动条。频道卡固定为 3 列 × 2 行；来话历史固定显示 5 行并分页。
- 顶部标题、BM 状态、RTT、有效丢包值和短暂事件位于同一行。短暂事件紧随最后一个有效指标显示。
- 下方连接配置与日常控制各占一半。连接配置由 5 个等高设置行组成，最底部只有 BM 连接切换和保存按钮。
- 串口行提供 Wires-X 端口、CAT 端口、波特率和串口连接切换。CAT 模式、MAIN 频率和功率等宽排列；选择“应用”后一次提交三项设置。功率预设为 5、10、15、25、50 W。
- 连接区保留呼号、DMR ID、设备编号、BM 服务器、端口、主机名、API key 与密码。CAT 当前读值紧邻对应标题显示。
- 日常控制保留频道录入、BM 静态组、音频设备和播放/发送增益。频道 ID 可手输，也可选用“460997 中国鹦鹉”“46001 组呼”或“91 组呼”。
- BM 静态组区域保持固定尺寸。未提供 API key 时，列表上显示“需启用BM API key”；配置 API key 后由程序启用对应管理操作。
- 音频设备选择位于增益区域上方，当前增益值显示在各滑块旁。频道卡显示监听、目标和收发状态；短暂操作反馈显示在标题行。

请在使用前核对电台模式、串口、音频设备、呼号和 DMR ID。RenderOnly、离线模块和 Native 自动化检查没有连接真实电台、串口、音频或 BM 服务，也不包含 PTT/RF 验收。
