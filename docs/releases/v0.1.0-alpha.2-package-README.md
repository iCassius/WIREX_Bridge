# WIREX Bridge v0.1.0-alpha.2

## 下载并启动

从此版本的 GitHub Release 下载 `download-release.ps1`，然后在保存脚本的目录运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\download-release.ps1 -Tag v0.1.0-alpha.2 -Destination C:\WIREX-Bridge-v0.1.0-alpha.2
```

下载器会校验文件长度和 SHA-256，并还原便携目录。打开还原出的目录，双击 `start-ui.cmd`。

首次使用时，在 FTX-1 上设置 HRI Mode 为 `ON`、Node Mode 为 `DIRECT`，连接 USB 并关闭官方 WIRES-X 程序。桌面界面打开“设置”后，填写自己的 BM 连接信息，选择现有 BM 密码文件，并保留 `auto` 设备选项，或在界面中选择本机设备。保存后界面会开始连接。

在主界面选择中国鹦鹉私呼、TG91 收听、TG46001 收听或已保存目标。连接过程中更改目标后，按“切换目标”；配置未更改时可按“重新连接”。手咪上行由实体 PTT 控制。

## 外部用户配置

默认设置保存在便携目录的 `private/user-config`。要在不同便携版本间共用配置，可建立外部目录，并在其中创建 `bridge-directory.txt`，只写一行当前便携目录的完整路径。用该配置目录启动桌面界面：

```powershell
.\start-ui.cmd -UserConfigDirectory C:\WIREX-Bridge\user-config
```

`start-user-config.cmd` 是命令行桥接入口，也可用同一 `-UserConfigDirectory`。配置目录保存连接参数、稳定设备标识、两路音量和版本目录指针。音量范围为 0.25x–16x，默认电台播放增益为 1x、手咪发送增益为 16x；保存后在下次连接时生效。

BM 密码保存在单独的本机文件中；`password-file-path.txt` 只记录该文件的路径。不要分享密码文件或个人配置。更多本机设置说明见便携目录中的 `docs/配置与桌面操作.md`。

## 退出

使用“停止并退出”或关闭窗口结束程序。通话上行仍由实体手咪 PTT 驱动。
