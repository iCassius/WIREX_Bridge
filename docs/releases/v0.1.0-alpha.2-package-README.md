# WIREX Bridge v0.1.0-alpha.2

> 操作说明草稿。桌面入口与设置页面仍待完成独立审查；最终包内文案应按已验证的窗口名称和控件调整。

## 下载并启动

先从该版本的 GitHub Release 下载 `download-release.ps1`。在包含 `tools` 目录的 alpha.2 源码 Tag 工作树中运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tools\download-release.ps1 -Tag v0.1.0-alpha.2 -Destination C:\WIREX-Bridge-v0.1.0-alpha.2
```

下载器会校验各文件的长度和 SHA-256，并还原目录结构。打开还原出的目录，双击 `start-ui.cmd` 进入桌面控制界面。

首次使用时，在设置中选择要运行的便携目录，并填写自己的 BM 连接信息。连接 FTX-1 USB，将 HRI Mode 设为 `ON`、Node Mode 设为 `DIRECT`，并关闭官方 WIRES-X 程序。启动后使用实体手咪 PTT 发话和结束上行；通过桌面界面的停止操作结束程序。

## 用户配置和音量

可用 `start-user-config.cmd` 从外部用户配置目录启动所选便携版本。先创建用户配置目录，并在其中创建 `bridge-directory.txt`，只写一行当前便携目录的完整路径。然后可在便携目录运行：

```powershell
.\start-user-config.cmd -UserConfigDirectory C:\WIREX-Bridge\user-config
```

需要跨版本保留设置时，让不同版本入口使用同一个用户配置目录。两路增益默认分别为 `1.0x` 和 `16.0x`，可设置在 `0.25x` 至 `16.0x` 之间。也可以在启动命令中传入 `-RadioPlaybackGain` 和 `-MicTransmitGain` 调整；设置保存在该用户配置目录中。

连接参数保存在 `connection-profile.json`，音量保存在 `audio-settings.json`。音量分别控制电台扬声器回放和手咪上行。BM 密码保存在独立文件中；`password-file-path.txt` 只记录密码文件路径。不要把密码文件或个人配置发送给他人。

## 退出

使用桌面界面的“停止并退出”结束程序。该操作请求核心有界停止并关闭其拥有的资源；它不控制电台 RF 状态。通话上行仍由实体手咪 PTT 控制。
