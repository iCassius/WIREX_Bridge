# WIREX Bridge v0.1.0-alpha.2

私有 alpha 版本在 FTX-1 DIRECT 与 BrandMeister 语音桥接上增加 Windows 桌面控制入口和统一用户配置入口。桌面入口为 `start-ui.cmd`；命令行桥接入口为 `start-user-config.cmd`。

## 功能范围

桌面界面显示当前核心进程报告的 HRI、音频和 BM 状态，管理连接配置及两路音量，并提供停止、重新连接和切换目标操作。控制管道只接受停止请求；通话上行仍由实体手咪 PTT 驱动。46001 组呼继续禁止上行。

FTX-1 LCD 呼号/房间显示和 RF 节点路由仍处于研究阶段，本版不实现这些功能。电台 RF 状态在界面中显示为未知；本版没有完成电台、USB 音频和 BM 的联合 HIL。

连接 profile、音量、稳定设备标识和版本目录指针保存在本机用户配置目录。profile 不存 BM 密码；`password-file-path.txt` 只记录单独密码文件的路径。状态快照每秒写入 `ui-runs/<GUID>/status.jsonl`，文件当前会随运行时长增长；有界保留将纳入后续版本。

## 验证

Windows PowerShell 5.1 离线检查覆盖状态记录校验、运行会话顺序和新鲜度、进程监督器生命周期、设备预检取消、桌面窗口渲染、用户配置启动和桥接启动器。C++ builder 清单包含 28 项测试，其中包括 `ui_pipe_test`。本版最终构建的准确测试结果、文件清单和 SHA-256 以同版本 `manifest.json`、`build-provenance.json` 及发布页为准。

这些离线检查不会启动电台或执行 BM 语音通话，也不能替代尚未完成的硬件联合验证。

## 下载与运行

从本版本 GitHub Release 单独下载 `download-release.ps1`，并在保存该脚本的目录中运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\download-release.ps1 -Tag v0.1.0-alpha.2 -Destination C:\WIREX-Bridge-v0.1.0-alpha.2
```

下载器会核对 manifest 中的文件长度和 SHA-256，并还原便携目录。首次启动步骤见[包内操作说明](v0.1.0-alpha.2-package-README.md)。

对应 Git Tag 保存完整源码和构建脚本；GitHub Release assets 提供便携运行文件与下载脚本。第三方源码、许可文本及来源记录随对应源码 Tag 保存。
