# WIREX Bridge v0.1.0-alpha.2

> 私有 alpha 预发布说明草稿。alpha.2 的 Windows 桌面界面和打包验证仍在收尾；最终测试结果、源码提交与文件摘要以发布包 `manifest.json`、`build-provenance.json` 和 Release 页面为准。

## 版本范围

alpha.2 候选版在现有 FTX-1 DIRECT 与 BrandMeister 语音桥接上，加入 Windows 桌面控制入口和统一用户配置入口。桌面入口为 `start-ui.cmd`；命令行配置入口为 `start-user-config.cmd`。最终包必须包含这两个入口及相应 UI、配置和核心文件，才能按本说明发布。

外部用户配置目录可由 `-UserConfigDirectory` 指定，并在该目录中保存连接 profile、两路音量设置和版本目录指针。`bridge-directory.txt` 选择启动所用的便携版本；可将多个便携版本切换到同一用户配置目录。连接 profile 不存密码，`password-file-path.txt` 只记录密码文件路径。

桌面控制管道只接受受限的退出请求；它不提供软件 PTT 命令。通话上行仍由实体手咪 PTT 驱动。固定的 46001 组呼继续严格禁止上行。

## 测试与设备验证

当前候选 builder 测试清单包含新增 `ui_pipe_test`，并按 builder 清单执行。本文不提前报告测试数量或通过结果；最终 clean build 完成后，请核对随包 manifest 与 builder provenance 中的固定测试名称、顺序和结果。

alpha.2 最终包尚未完成用户 HIL。静态代码、离线测试和桌面界面检查不能代替电台、USB 音频与 BM 的联合实测。

FTX-1 LCD 当前呼号/房间显示和 RF 节点路由仍处于研究阶段，本版不实现这些功能，也不声称控制 DIRECT 模式下的 RF 收发。

## 下载与运行

请从本版本的 GitHub Release 单独下载 `download-release.ps1`，在源码 Tag 工作树中运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tools\download-release.ps1 -Tag v0.1.0-alpha.2 -Destination C:\WIREX-Bridge-v0.1.0-alpha.2
```

下载器会核对本版本 manifest 和独立文件 asset，并还原便携目录。启动步骤见[包内操作说明](v0.1.0-alpha.2-package-README.md)。

对应 Tag 保存完整源码和构建脚本；Release 独立 asset 提供便携运行文件与下载脚本。仓库中的第三方源码、许可文本及来源记录随源码 Tag 保存。
