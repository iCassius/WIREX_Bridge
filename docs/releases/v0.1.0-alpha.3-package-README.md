# WIREX Bridge v0.1.0-alpha.3

## 下载并启动

从此版本的 GitHub Release 下载 `download-release.ps1`，然后运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\download-release.ps1 -Tag v0.1.0-alpha.3 -Destination C:\WIREX-Bridge-v0.1.0-alpha.3
```

下载器会校验 manifest、文件长度和 SHA-256，并还原便携目录。打开还原出的目录，双击 `start-ui.cmd`。

首次使用时，在 FTX-1 上设置 HRI Mode 为 `ON`、Node Mode 为 `DIRECT`，连接 USB 并关闭官方 WIRES-X 程序。桌面界面“设置”中填写自己的 BrandMeister 连接信息、密码文件路径和音频设备；保存后启动连接。连接 profile、设备选择和音量设置保存在本机用户配置中。

## 来话身份与功能范围

每通通过接收过滤的 BM 来话，程序会生成 `ID` 加十进制 DMR Source ID 的数字标签，并写入 HRI T3 起始记录的 source 字段。桌面主界面显示 Native 报告的标签状态和数字标签；该标签不是经过呼号数据库确认的呼号。FTX-1 LCD 上的实际文字、显示时机和结束后的清除行为仍待集中设备联测，界面将屏幕状态显示为“未知”。

开始新运行前，界面会清理可确认已经结束的旧运行目录，最多保留 10 个目录、总量不超过 50 MiB。当前 Native run 的 `status.jsonl` 不受此保留上限约束，长时间运行时仍可能继续增长；无法确认已结束的目录会跳过清理。

此版本不提供 C4FM RF 节点转发或 BM 到 RF 的发射功能。界面中的数字标签说明 Native 已准备 HRI 来源字段，`display=unknown` 则说明尚未确认电台实际显示结果。

## 本机配置和退出

BM 密码和用户连接配置保存在本机路径中，不包含在发布目录内。不要分享密码文件或个人配置。更多设置说明见 `docs/配置与桌面操作.md`、`docs/连接配置.md` 和 `docs/音量调节.md`。

使用桌面界面中的“停止并退出”结束程序。手咪上行仍由实体 PTT 控制。
