# WIREX Bridge v0.1.0-alpha.3

本私有 alpha 版本更新 DIRECT BrandMeister 桌面桥接，包含设备选择与音量控件修正，并将每通已接受 BM 来话的数字 Source ID 标签写入 HRI T3 起始记录。

## 功能范围

- 每通通过接收过滤的 BM 来话生成 `ID` 加十进制 DMR Source ID 标签。该标签不是 WIRES-X 呼号映射结果。
- 桌面界面用于连接设置、设备选择、音量调节和运行状态显示；当前来话区域显示 BM 来话信息，HRI 来源标签区域显示已准备的数字 Source ID 标签。
- FTX-1 LCD 的实际显示内容、显示时机与结束后的清除行为仍待合并设备联测。`lcd_source_identity.display` 保持 `unknown`，直到有屏幕观察。
- 开始新运行前，界面清理可确认已结束的旧运行目录，最多保留 10 个目录且总量不超过 50 MiB。当前 Native run 的 `status.jsonl` 不受此上限约束，长时间运行时仍可能增长；未能确认已结束的目录会跳过清理。
- C4FM RF 节点与 BM→RF 发射未包含在此软件实现中。该版本不宣称完成 RF 路由。

## 验证

发布前的 clean build、C++ 测试、包审计及下载验证结果以本版本 `manifest.json`、`build-provenance.json` 与发布页为准。软件测试使用合成数据和 loopback，不替代电台 LCD、音频、PTT、BM 或 RF 设备联测。

该版本的实际硬件验证与未验证范围记录在发布审计结果中；本机用户 profile、音量配置和 BM 密码不随包提供。

## 下载与运行

从此版本 GitHub Release 单独下载 `download-release.ps1`，并在保存脚本的目录中运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\download-release.ps1 -Tag v0.1.0-alpha.3 -Destination C:\WIREX-Bridge-v0.1.0-alpha.3
```

下载器会校验 manifest、文件长度和 SHA-256，并还原便携目录。首次启动步骤见随包提供的 `README.md`。
