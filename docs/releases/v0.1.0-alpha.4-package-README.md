# WIREX Bridge v0.1.0-alpha.4

## 启动

在 FTX-1 上启用 HRI、选择 `DIRECT`，并进入 `WIRES-X HRI` 界面。关闭官方 WIRES-X 应用，连接电台 USB 线。打开本目录，双击 `start-ui.cmd`。

主界面连接后会报告 BM、HRI、串口和音频状态。设置页将 BM 服务器、发射目标、接收目标及上/下行音量分开显示。COM5 与 FTX-1 USB Audio 是已知设备；设备下拉菜单会优先显示并选择可用的已知设备。

## BrandMeister 连接

- 服务器可选 `BM China 4602`（`43.129.83.124:62031`）或填写自定义主机名/IPv4 与 UDP 端口。
- 直接使用 `start-ui.cmd` 时，呼号、Gateway ID、Source ID、BM 密码文件路径与音频选择默认保存在便携目录的 `private/user-config`。需要跨版本复用时，可把外部目录传给 `start-ui.cmd -UserConfigDirectory <目录>`；本机的 `start-my-bridge.cmd` 已使用这一方式复用个人配置。密码正文仍由用户自己的密码文件保存，不随程序文件夹分发。
- 服务器连接状态与当前接收过滤目标是不同状态。要听到组呼，BM 服务器必须实际向设备送达这个 Talkgroup 的语音数据。

## 收听与发射

主界面会分别列出 BM 接收目标、发射目标和是否允许发射。用户更改目标后，下次连接时生效。

- **TG91 收听：**接收 `91/G/TS2`。本配置禁止本次运行的所有 BM 上行，手咪或键盘动作不会改变只收策略。
- **中国鹦鹉回音：**发射 `460997/P/TS2`；接收发往本机 Source ID 的私呼回包。该回包还需符合来自当前鹦鹉目标、呼叫类型和时隙条件。
- **其他目标：**发射和接收分别选择；核心按屏幕显示的目标过滤 BM 网络帧。旧版 profile 缺少接收字段时，启动时沿用旧版从发射目标推导接收目标的行为。

听 TG91 与测试鹦鹉回音是不同运行策略。需要上行测试时，选择允许发射的鹦鹉目标；选择只收配置后，状态栏会明确显示发射已禁用。

## 已知验证边界

程序不会把 UI 中准备的 HRI 标签当作电台 LCD 已显示。FTX-1 屏幕文字仍待实际观察；当前版本也没有 C4FM RF→BM 或 BM→RF 转发。

用户报告鹦鹉回音期间电台似乎继续触发 PTT。本版软件日志能核对网络数据报、BM 接收/发射计数、HRI T3/T0 和播放队列；这些数据不能单独确认电台实际 PTT 状态。请在本版实机验收中同时观察红色 X、PTT、耳机/扬声器回音和运行日志。发布 build provenance 记录离线测试和打包结果。

## 退出

使用“停止并退出”结束运行，程序会关闭本次启动的核心进程和设备句柄。本机用户配置按启动参数选择保存位置：默认位于便携目录的 `private/user-config`，指定 `-UserConfigDirectory` 后使用该外部目录。不要分享密码文件或个人配置。
