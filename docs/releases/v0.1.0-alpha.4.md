# WIREX Bridge v0.1.0-alpha.4

## 版本范围

alpha.4 将 BM 发射目标和用户选择的接收目标分别配置。alpha.3 曾从同一个发射目标生成接收过滤器，所以 BM 服务器已送达的 TG91 组呼会进入界面日志，随后又在本机按目的 ID 与呼叫类型过滤，电台收不到语音。

本版加入 `BM China 4602` 服务器预设（`43.129.83.124:62031`），同时保留自定义服务器。服务器、收听目标和发射目标在设置中分别显示。TG91 收听配置将 BM 接收目标设为 `91/G/TS2`，核心禁止所有 BM 上行；中国鹦鹉配置使用 `460997/P/TS2` 发射，并接收发往本机 Source ID 的私呼回音。只收模式不启用私呼回音接收规则。

连接 TG91 需要 BrandMeister 向该热点送达对应组呼流。客户端只接受配置的 RX 目标和满足本机身份、呼叫来源、类型及时隙条件的私呼回音；它不会接收任意 Talkgroup 或发给其他 DMR ID 的私呼。

## 验证状态

发布前需通过与 alpha.3 相同的 35 项或更多 C++ 离线测试、PowerShell 配置/UI 检查、正式 clean build 和包文件核验。离线检查覆盖发射与接收目标分离、旧配置兼容、TG91 的上行禁止、鹦鹉私呼回音过滤、BrandMeister 4602 预设及配置迁移。最终结果以本版 build provenance、manifest 和已发布资产为准。

用户报告鹦鹉回音期间电台似乎继续触发 PTT。现有 alpha.3 日志显示 BM 下行 PCM 经播放队列排空，且下行期间软件没有增加 PTT start 或 BM 上行数据报；该日志没有观察电台硬件 PTT。因此本版不会把这个现象记为已修复，仍需以本版实机日志、红色 X/PTT 状态和扬声器听音完成验证。

本版不含 C4FM RF→BM 或 BM→RF 转发。FTX-1 LCD 的真实显示内容仍未知；HRI Source ID 字段的实际屏幕结果需实机观察。

## 本机运行

本项目向用户提供本机便携目录，不需要 ZIP。直接双击随包 `start-ui.cmd` 时，profile、设备选择、音量值和密码路径默认保存在该便携目录的 `private/user-config` 中；这一默认位置会随便携目录一起移动或复制。要跨版本复用个人设置，应使用带有 `-UserConfigDirectory` 的启动入口。本机 `start-my-bridge.cmd` 已通过该参数指向同一个外部用户配置目录，能跨版本选择发布目录并复用个人 profile；密码正文仍留在用户自己的密码文件中，不随发布包携带。

TG91 实机收听需电台连接 HRI、DIRECT 并进入 WIRES-X HRI 界面；USB 音频选择电台对应的 USB Audio 端点。听音和鹦鹉回音是不同验收配置：TG91 只收，`parrot-cn` 用于受控私呼回音和手咪上行测试。
