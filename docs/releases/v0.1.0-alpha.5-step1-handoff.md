# alpha.5 第1步交接验收表

本表用于先验无设备诊断和配置兼容，再决定是否进入 R106 第2步。保留 alpha.4 文件夹和个人原配置。通用 manifest 审计通过后，交付流程会在独立测试目录放置三份获准配置副本；用户不需手工改 JSON。请把每项实测结果、日志路径（去除凭据）和日期补在“结果”列。

协议字段和边界见 [`R106_IPC第二版.md`](../R106_IPC第二版.md)，配置迁移规则见 [`R106_配置迁移与测试.md`](../R106_配置迁移与测试.md)。

## 结果记录

异常帧、重复 request_id、缓存边界和有界收尾由原35项之后新增的 `ui_control_protocol_v2_test` 离线验证；schema 迁移和复杂策略拒启由 PowerShell fixture 测试验证。通用 manifest 完成审计后，独立测试目录内才会额外出现三份获准配置副本；它们不会加入通用 `manifest.json`、发布资产或分享内容。结果以各项实际离线测试输出和本地构建生成的 `build-provenance.json` 为准。用户不需要手动编辑或输入配置 JSON；手动操作仅包括 P2 的 `test-control.cmd` 与 U1 的 `start-step1-test.cmd`。

仅在 P1、P2、C1–C3 和 U1–U2 的结果有证据后，根会话才决定后续多组运行时工作。本表未填写的设备行为不视为通过。当前授权工作未启动串口、音频或 BM 连接。
