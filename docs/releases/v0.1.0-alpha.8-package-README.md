# WIREX Bridge v0.1.0-alpha.8 本机合并测试包

## 启动

双击 `start-wirex-bridge.cmd`。这是本包唯一推荐的启动命令。首次运行或需要修改连接信息时，在主窗口打开设置窗口，选择 HRI 串口和音频设备并保存。

没有本机配置目录指针时，连接设置保存在包内 `private/user-config`。本机若要让多个测试版本共用同一份设置，可在包内 `private/user-config-directory.txt` 写入一行绝对目录路径；此本机文件不属于通用包清单。

本机之前的配置文件已备份在 `app/private/config-backups/R110`。如需恢复旧配置，将该目录中的四个文件复制回 `app/private/user-config`；请先关闭 WIREX Bridge。通用包不含个人连接配置或密码文件内容。请在设置窗口选择现有密码文件；包内不会复制密码文本。

## 功能范围

alpha.8 沿用 alpha.7 的动态组控制与无语音下行收尾功能。运行页中的“加入本机收听”和“激活动态组”是独立操作：前者修改本机接收规则；后者只在控制能力、BM 会话和呼叫资源满足条件时发送一次无语音 Quick Call。Quick Call 不开启语音发射许可。

若下行呼叫在收到任何有效语音前以 EOT 或接收 watchdog 结束，核心跳过 HRI T3，并清理接收资源。运行记录包含 `rx_call_end_reason`、`rx_call_missing_packets` 和 `rx_call_accepted_voice_bursts`。

## 验证范围

alpha.8 启动入口修复由 R110 说明记录。最终包的 PowerShell 文件解析、`PrepareOnly` 和隔离路由诊断结果应以包级验收记录为准。本 README 描述包的预期使用方式，不单独证明已完成构建或设备验收。

离线解析、预检和内存 sink 诊断不覆盖实际 COM 通信、音频输入输出、BrandMeister 网络连接、PTT、FTX-1 机身 BUSY/TX LED 或 RF 行为。
