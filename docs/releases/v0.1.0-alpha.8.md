# WIREX Bridge v0.1.0-alpha.8 交付说明

alpha.8 准备延续 alpha.7 的 R109 功能，并修复 Windows PowerShell 5.1 将包内 UTF-8 启动脚本按系统 ANSI 代码页读取后产生的语法错误。包根目录改用一个 `start-wirex-bridge.cmd`，经 `tools/start-wirex-bridge.ps1` 和 `start-ui.ps1` 启动 UI；启动器向 UI 传递诊断参数时也走同一条链路。alpha.7 已交付目录保持不变。

本次还准备包级回归：递归解析最终包内全部 `.ps1` 和 `.psm1`，并经唯一 ASCII CMD 入口运行 `PrepareOnly` 与隔离 `RoutingDiagnosticAutoTest`。R110 的 source-mapped 包级检查已使用 Windows PowerShell 5.1 验证 5 个包内脚本可解析，并通过上述两个入口模式和 WPF 离线诊断。测试使用获准的 R109 Native，不打开 COM 或音频流、不启动正常 Native 会话，也不连接 BrandMeister。后续仍需获准的完整构建和正式包审计；当前文档不表示 alpha.8 已构建、已发布或通过硬件验收。

个人连接设置、密码路径指针和密码文件不属于通用发行内容。alpha.7 的本机配置已先备份并迁移到长期配置目录；alpha.8 验收和本机指针切换完成前，不清除旧 build 产物。密码文件内容不得读取或复制进通用包。
