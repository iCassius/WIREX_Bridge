# WIREX Bridge v0.1.0-alpha.9 交付说明

alpha.9 集成 R111 的收听与起呼目标分离、最近 50 条通话记录、逐路由 TS、发射 CC、高级 RadioID 单 ID 查询和本机音量控制。查询需要用户明确点击；RadioID 响应缓存写到当前 `UserConfigDirectory/radio-identity-cache.json`，不会进入 Git 或通用包。发布 profile 带运行所需的 `ui/windows/RadioIdentity.psm1`，不带 `tools/test-radio-identity.ps1`、测试专用 `tools/test-radio-identity-http-server.ps1` 或缓存数据。

多条收听路由构成本机准入规则，不按显示顺序形成优先级；当前媒体 owner 忙时不自动抢断正在播放的来话。TS1/TS2 字段用于软件路由与目标选择；当前 `bm_session.Profile.slot_flags` 默认和网络 metadata 为 `4`（simplex），不宣称 FTX-1 有 DMR 双时隙 RF，也不承诺同时播放两个时隙。CC 是高级 DMR 发射编码/上报参数，不是 C4FM DG-ID；接收路由不按 CC 过滤。B 区显示内置预设、本机 RX allow_groups、手动输入的 TG/TS、明确选取的历史项和用户本机频道收藏。收藏的 `normal`/`dynamic`/`static` 分类只描述用户本机组织方式，不表示 BM 已建立对应服务器订阅；当前没有 BM 静态订阅 readback。动态组 Quick Call 会发送空呼叫控制帧，用户确认 BrandMeister Dashboard 会显示相应记录；其他终端展示方式未知。本版本没有声称支持静默添加动态组的官方 API。

alpha.8 已有音量滑块。alpha.8 的 TG91 用户听感为正常但略小：该次本机运行记录中的有效播放增益为 1.000x，clipped samples 为 0；保存的 5.959x 配置值没有反映到该次运行。alpha.9 在状态卡和设置页分别显示运行时实际增益、保存值与削波计数，并提示修改后需要重连才能生效；这些显示仍需新版本实机听音确认。

FTX-1 机身 BUSY/TX LED 与串口行为没有改动。官方静态证据定位到 10 字节 HRI `Src CallSign` 字段，但尚未确认该字段是否显示在 FTX-1 LCD。C4FM RF 双向 codec/serializer 尚未接入运行链，相关发射功能还未完成实现。R111 没有连接 COM、音频、BrandMeister，没有触发 PTT 或 RF。
