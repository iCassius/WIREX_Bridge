# WIREX Bridge v0.1.0

这是一个适用于 Windows 的便携目录。解压或复制整个文件夹后，双击根目录中的 `WirexBridge.exe` 启动。

首次启动时，程序会在 EXE 同目录创建通用 `config.json`。该文件使用统一的 PortableConfig schema，呼号、BM 密码和 API key 默认留空。请在连接前于程序设置中填写自己的资料。启动器不会读取、覆盖或打印已经存在的配置；如果配置无法读取、解析或验证，程序会停止启动。

`runtime` 文件夹保存 Native、WPF 界面和内部脚本，请保留该文件夹及其内容。正常启动不需要从命令提示符或 PowerShell 运行内部脚本。

`WirexBridge.exe --no-connect` 会打开界面，但不自动连接 CAT、HRI、BrandMeister 或音频。`WirexBridge.exe --validate-config` 只创建或校验配置，然后退出，不打开界面。

`--routing-diagnostic <隔离目录>` 供离线验收使用：它启动完整的 WPF/Native 路由诊断，要求提供独立的临时隔离目录。此模式只把 EXE 目录用于路径拒绝比较，不读取或写入 EXE 根目录的 `config.json`。普通用户无需运行此模式。

当前 v0.1.0 候选未完成设备、HRI、音频、PTT 或 RF 实机验收。正常使用时请先按本机设备和连接方式设置配置，再依据项目验收记录验证目标设备。
