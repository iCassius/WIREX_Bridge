# WIREX Bridge v0.1.0

首个 stable 便携目录发行候选。用户从根目录启动 `WirexBridge.exe`；Native、WPF 和内部脚本位于 `runtime/`。配置文件位于启动器同目录，首次启动时由共享 `PortableConfig.psm1` 初始化。

本轮用户可见内容包括动态组激活请求去重与静态/动态组来源标记、中文频道预设和纯 ID 输入、可点击展开的下拉框主体，以及播放和发送增益的胶囊形滑块。界面只在收到本机有效发送结果后显示“已发送”；这不代表 BM 服务端确认加入。启动器可从根目录启动并在缺少配置时自动创建通用配置，呼号、BM 密码和 API key 初始留空。

发布清单分别记录 C++ Native EXE 的完整离线构建证据，以及 C# launcher 的本机 .NET Framework `csc.exe` 编译器、launcher 源码 SHA-256、输出 SHA-256 和构建 provenance。发布目录不包含用户配置、呼号、密码、BM API key、日志或本机目录；获批的 HRI 协议模板保留在 `runtime/private/device-y.bin`，并按固定 SHA-256 校验。

本版本不包含当前源码的设备、HRI、音频、PTT 或 RF 实机验收结果。此说明只描述发布包和已记录的构建证据。
