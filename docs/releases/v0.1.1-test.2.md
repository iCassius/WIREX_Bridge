WIREX Bridge v0.1.1-test.2 使用 WIRES-X DIRECT：FTX-1 通过 USB 连接电脑，由电脑通信，不走射频链路。AP RADIO 是 FTX-1 作为无线接入点供其他电台经射频接入；AP PC 是 FTX-1 连接电脑，通过 C4FM 射频通信。

下载并解压 ZIP，运行 `WirexBridge.exe`；首次启动会在程序旁创建 `config.json`。在连接配置中选择设备并填写 BrandMeister 资料，然后加入组，可按需使用 PTT、调节音量或切换语言。
