## v0.2.3 改进

- **来话显示国家/地区**：频道卡片、当前来话、最近来话与来话历史在呼号后显示 RadioID 返回的国家与省/州（如 `BD0LAB China Guangdong`），过长省略，悬停看全文。
- **来话历史“设为单呼目标”**：无论原记录是组呼还是私呼，都以来呼方 DMR ID 作为单呼 PTT 目标，并自动加入以呼号命名的单呼频道。
- **新增动态组自动激活**：BM 已连接时添加动态组（含“加入收听”）会立即激活；未连接时在连接后自动激活。
- **音频设备切换更快**：切换输入/输出不再等待当前通话结束；刷新设备在后台枚举，不再卡界面。切换后播放从完整预缓冲重新开始，减少切换后的卡顿。
- **BM 密码 / API Key 旁恢复“设置”链接**，分别打开 BrandMeister SelfCare 与 API Key 页面。
- **标题栏对齐**：标题、版本标签与作者在同一中线。

## v0.2.1 修复

- **电台与 BrandMeister 解耦**：不填写 BM 配置也能直接连接电台并使用 CAT、音频、频率/功率/模式；BM 配置不全时只显示“BM 未配置”，不再报核心错误。补全后无需重启、无需断开电台即可连接 BM。API Key 仅静态组功能需要。
- **未收听流量提示更明确**：区分组呼与私呼，显示目标（TG 或“→ 本机”）、发起方与时隙；发给别人的私呼只提示、不再提供“加入收听”；通话尾包等中间态不再误报。dev 日志新增 `[rx-filtered]` 记录。
- **身份与许可**：仓库内置示例改为占位呼号 `N0CALL`（请填写你本人的呼号与 DMR ID）；新增 GPL-3.0 `LICENSE` 与合规声明。

v0.2.0 是首个原生单进程 GUI 版本：一个 `WirexBridge.exe` 直接运行，不再需要 PowerShell、WPF 或启动器。界面、引擎、CAT 与 BrandMeister 服务都在同一进程内。

## 下载与运行

- 解压 ZIP，双击 `WirexBridge.exe`。支持 Windows 10（1703 及以上）/ Windows 11 x64。
- 首次启动会在 EXE 旁生成 `config.json`；文件保存明文凭据，请勿外传。
- 包内只有 `WirexBridge.exe`、`licenses/`（GPL-3.0、ISC、MIT 许可文本）和本说明。HRI Y 模板已内嵌，不再附带 `device-y.bin`。

## 首次设置

1. **设备**：选择 HRI 串口、CAT 串口和两个 USB 音频设备，FTX-1 通常可自动识别。
2. **BrandMeister**（可稍后填写）：填写你本人的呼号、DMR ID、设备编号与 BM 密码，选择服务器，保存配置；API Key 仅静态组功能需要。
3. **组**：添加静态组或动态组；静态组会在启动时从 BM API 同步。
4. 分别连接电台与 BM，手咪 PTT 上行，来话可在电台或本机播放。

## v0.2.0 相对 v0.1.x 的主要变化

- 单进程原生 GUI（Dear ImGui + DirectX 11），去掉跨进程 IPC 和 PowerShell 胶水层。
- 电台与 BM 可分开连接；没有电台时 BM 来话在本机播放。
- HRI DIRECT 连接 FTX-1，CAT 读写频率、模式与功率；HRI 掉线后自动重连（3 s、6 s、10 s 退避）。
- BrandMeister 连接、来话接收与手咪 PTT 上行，鹦鹉回放验证通过。
- 静态组从 BM API 同步；静态组可静音，动态组可停用/启用；来话播放中的快速呼叫会延后执行。
- 主界面显示 BM RTT 与本次会话丢包率。
- 两个 USB 音频设备的音量滑块直接设置 Windows 端点音量。
- HRI 模式下可设置 TX 功率、频率（144–148 / 430–440 MHz，1 kHz 步进）与模式（FM、C4FM-DN），经动态 Y 记录下发。
- 新增 FM 中继、中英文切换；添加频道时呼叫类型默认为组呼。

## FM 中继（实验）

这是官方未支持的功能，仅用于试验。电台收到 FM 信号且静噪打开时，程序把 USB 声卡采集的音频编码后发往 BM。

1. 先点右上角“启用中继”，再点随后出现的“FM”按钮；电台已连接时需断开重连后生效。
2. 保持 CAT 连接；程序每 100 ms 只读查询静噪状态。
3. 静噪打开即开始转发，关闭即结束；单段最长 180 秒。

来话播放期间不会启动中继，中继进行中手咪也不能打断。每段记录写入 `<exe>/private/runtime/relay-log.jsonl`。目前只支持 FM，C4FM 中继尚未实现。

## 已知限制

- C4FM 中继未实现，FM 中继为实验功能。
- C4FM-DN 模式没有 PC 语音路径，界面会提示；该模式下手咪上行与 FM 中继不可用。
- FTX-1 屏幕显示来话呼号仍为实验性。
- 125% DPI 缩放与中文输入法未完整验证。
- 正式版默认关闭 dev 日志；需要时用 `WirexBridge.exe --dev-log` 开启，日志写在 `<exe>/logs/`。
