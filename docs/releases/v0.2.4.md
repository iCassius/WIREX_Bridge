# WIREX Bridge v0.2.4

## Updates

- Fixed English-mode status, preset, device, and error text that could remain Chinese after switching languages.
- New installs follow the Windows UI language when it is English; existing saved language choices are preserved.
- Added the BrandMeister Parrot as **Private 9990** to fresh default configurations. The existing China Parrot and TX target are unchanged.
- Expanded the offline BrandMeister master list from 5 to 42 entries using the Pi-Star MMDVM host list checked on 19 Nov 2026: [DMR_Hosts.txt](https://www.pistar.uk/downloads/DMR_Hosts.txt).
- Added bilingual offline UI screenshots to the README.

## 更新内容

- 修复英文界面中仍显示中文的状态、预设、设备提示和错误信息；切换语言后会刷新缓存的文案。
- 英文 Windows 新安装默认使用英文界面；已有配置中的语言选择保持不变。
- 新增 BrandMeister 鹦鹉**私呼 9990**默认频道；保留中国鹦鹉和原有发射目标。
- 根据 2026-11-19 核对的 Pi-Star MMDVM 主机列表，将内置 BrandMeister Master 从 5 个扩充到 42 个。
- README 新增中英文离线界面截图。

BrandMeister 当前 Last Heard 页面仍可见私呼 Parrot 9990：[master.brandmeister.es](https://master.brandmeister.es/status/extra/heard.htm)。
