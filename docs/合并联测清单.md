## 连接配置回归

在最终候选的离线/启动器检查中完成下列项目；这些检查不要求现在打开设备或发起 BM 会话：

- 首次以 `start-profile.cmd` 启动时，启动器收集一次非秘密连接参数和设备选择，写入 `connection-profile.json`；退出后再次启动，确认参数和稳定 endpoint 选择从文件恢复。
- 传入任一固定 `-Preset` 时，即使便携根目录存在损坏的 `connection-profile.json`，启动仍使用固定预设，不读取该文件。
- 对已有 profile 用 `-Port`、`-WaveIn`、`-WaveOut` 覆盖时，确认覆盖只影响本次运行，文件内容不变；通过交互选择替换 `auto` 设备后，确认只保存用户明确选定的稳定 endpoint ID。
- 将 profile 指定的 endpoint 从设备列表移除后，确认启动明确报错并停止，不改选另一台设备；确认输入固定 endpoint 与自动输出选择不会拼成不同设备的音频对。
- 分别检查默认密码文件存在、显式 `-PasswordFile` 缺失和默认密码文件缺失的路径：显式缺失时报错；默认缺失时显示 native 隐藏输入提示。检查 profile、命令行和 JSONL 不包含密码正文。
