# 手工连接配置文件

## 使用方式

在便携目录根目录双击 `start-profile.cmd`，或从该目录运行：

```powershell
.\start-bm-radio-bridge.ps1 -Preset manual
```

首次运行会询问呼号、Gateway ID、本机 DMR Source ID、BM Master 地址和 UDP 端口、目标 ID、时隙、Color Code 与呼叫类型。启动器会把这些非秘密字段和设备选择写入便携目录的 `connection-profile.json`。下次以 `-Preset manual` 启动时，启动器读取该文件，不再逐项询问连接参数。

需要调整配置时，编辑该 JSON 文件；需要临时选择设备时，可将参数传给启动器：

```powershell
.\start-bm-radio-bridge.ps1 -Preset manual -Port COM5 -WaveIn 1 -WaveOut 3
```

`-Port` 指串口，`-WaveIn` 和 `-WaveOut` 指本次 WinMM 枚举的数字 ID。连接配置已存在时，这些参数只覆盖本次启动；profile 中保存的设备选择保持不变。首次创建 profile 时，启动器会保存本次显式选择。也可以用 `-ConnectionProfilePath` 指定另一个连接配置文件。

## 文件格式

文件采用 UTF-8 JSON，当前只接受 `schema_version` 为 `1` 的格式。顶层只能包含版本、连接参数和设备选择：

```json
{
  "schema_version": 1,
  "connection": {
    "callsign": "N0CALL",
    "gateway_id": 460999901,
    "source_id": 4609999,
    "master": "43.129.83.124",
    "master_port": 62031,
    "destination_id": 460997,
    "slot": 2,
    "color_code": 1,
    "call_kind": "private"
  },
  "devices": {
    "serial_port": "auto",
    "wave_in_endpoint_id": "auto",
    "wave_out_endpoint_id": "auto"
  }
}
```

`serial_port` 可设为 `auto` 或明确的 `COM` 名称；两个音频字段可设为 `auto` 或稳定的 endpoint ID。自动选择仍使用启动器的 HRI 串口与 USB Audio 发现规则。启动器会把 endpoint ID 映射到本次枚举得到的 WinMM 数字 ID，并继续让 native 核对 endpoint。已保存的明确 endpoint 若不在当前枚举中，启动会报错；选择 `auto` 时，发现规则遇到多个候选会要求手工选择，并把手工选中的稳定 ID 保存下来。

连接参数按 native 校验规则检查：呼号为 1 到 8 个可打印 ASCII 字符；Gateway ID 为 1 到 4294967295；Source ID 和目标 ID 为 1 到 16777215；Master 为 1 到 253 个不含空格的可打印 ASCII 字符；UDP 端口为 1 到 65535；时隙为 1 或 2；Color Code 为 0 到 15；呼叫类型为 `group` 或 `private`。JSON 字段必须唯一且完整，重复字段、未知字段、非整数数字、缺失设备选择和不支持的版本都会被拒绝。保存时先写临时文件，再原子替换目标文件。

## 优先级与凭据

未指定 `-Preset` 时默认继续使用 `parrot-cn`。四个固定 preset（`parrot-cn`、`parrot-global`、`listen-46001`、`listen-91`）直接使用各自固定字段，不读取 `connection-profile.json`；profile 仅由 `-Preset manual` 启用。native 会对手工连接参数重新做完整字段校验，并按目标、呼叫类型计算发送策略。

连接 profile 不保存密码。手工 profile 启动时，显式 `-PasswordFile` 指定的文件必须存在；未指定时，启动器优先使用便携目录 `private\bm-device-password.txt`，该文件不存在则由 native 在控制台隐藏输入密码。固定 preset 仍要求私有密码文件。启动参数只传密码文件路径，密码内容不进入连接 profile、命令行或日志。

音量继续单独保存在 `audio-settings.json`，与连接参数和私有密码分开。例如：

```powershell
.\start-profile.cmd -RadioPlaybackGain 1.25
```

这会将电台回放增益设为 `1.25x`，并保留另一项音量设置。
