# 音量调节

桥接器提供两项独立的 PCM 增益：`radio_playback_gain` 控制 BM 音频送到电台扬声器的播放电平，`mic_transmit_gain` 控制电台手咪音频送往 BM 的上行电平。两项默认值分别为 `1.0x` 和 `16.0x`，可设置范围为 `0.25x` 至 `16.0x`，最多三位小数。

在便携目录调整 TG91 收听时，可直接指定电台回放增益：

```powershell
.\start-listen-91.cmd -RadioPlaybackGain 1.25
```

传入的项目会保存到便携目录的 `audio-settings.json`，下次启动继续使用。省略某项时保留已保存值；首次启动会创建含默认值的设置文件，因此上例的手咪发送增益仍为 `16x`。若要同时调整两项，可运行：

```powershell
.\start-bm-radio-bridge.cmd -RadioPlaybackGain 1.25 -MicTransmitGain 12
```

JSON 只包含版本号和两项增益，启动器拒绝未知字段、重复字段、无效版本和超范围数值。

示例文件：

```json
{
  "schema_version": 1,
  "radio_playback_gain": 1,
  "mic_transmit_gain": 16
}
```

启动器把两项设置作为 native 参数传入。增益在单声道 PCM16 上缩放，超出 PCM16 范围的样本饱和到边界。JSONL 状态报告记录每路增益、增益前后 RMS/峰值和削波样本数；手咪发送样本在 BM 语音管线接受后计入，接收样本在 WaveOut 成功排队后计入。WaveOut 提交失败的接收帧不计入接收统计。
